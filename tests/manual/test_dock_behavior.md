# 底部栏行为测试

## 新行为说明
- 页面加载时，底部栏不会自动显示（即使之前已启用 globalDock）
- 按 Alt+S 可以打开/关闭底部栏
- 不需要选中文本也能使用 Alt+S

## 测试步骤

### 1. 页面加载行为
- [ ] 刷新页面或打开新页面
- [ ] 确认底部栏不会自动出现
- [ ] 确认页面正常加载，没有错误

### 2. Alt+S 打开底部栏
- [ ] 在没有选中任何文本的情况下按 Alt+S
- [ ] 确认底部栏出现在页面底部
- [ ] 确认输入框可以正常使用

### 3. Alt+S 关闭底部栏
- [ ] 底部栏显示时，按 Alt+S
- [ ] 确认底部栏被隐藏

### 4. 再次打开
- [ ] 底部栏隐藏后，再按 Alt+S
- [ ] 确认底部栏重新出现

### 5. 带选中文本测试
- [ ] 选中页面上的一些文本
- [ ] 按 Alt+S 打开底部栏
- [ ] 确认选中的文本出现在输入框中
- [ ] 确认功能按钮正常工作

### 6. 设置持久性
- [ ] 使用 Alt+S 打开底部栏
- [ ] 刷新页面
- [ ] 确认底部栏不会自动出现
- [ ] 按 Alt+S 可以重新打开

### 7. 自定义快捷键测试
- [ ] 在设置中将快捷键改为其他组合（如 Alt+Q）
- [ ] 测试新快捷键能正常打开/关闭底部栏
- [ ] 确认原来的 Alt+S 不再生效（除非设置为 Alt+S）

### 8. ESC 键测试
- [ ] 底部栏显示时，按 ESC 键
- [ ] 确认底部栏被隐藏

## 预期行为总结
1. **页面加载**：底部栏默认隐藏
2. **Alt+S 第一次**：创建并显示底部栏
3. **Alt+S 第二次**：隐藏底部栏
4. **Alt+S 第三次**：重新显示底部栏
5. **刷新页面**：底部栏不自动显示，需要按 Alt+S 重新打开
