📝 测试说明

选中下面的测试文本，查看智能命令建议功能：

  • 选中文本后，弹出框会自动显示
  • hover到输入框，会自动获得焦点
  • 输入框会自动显示智能建议
  • 使用 ↑↓ 键导航建议，Tab 补全，Enter 执行
  • 系统会智能检测文本类型并推荐相应操作

⚡ 快捷命令测试

选中任意文本后，在输入框中输入以下字符查看建议：

  • b 或 base - 显示Base64相关命令
  • m 或 md5 - 显示MD5命令
  • u 或 url - 显示URL编码命令
  • up 或 upper - 显示转大写命令
  • low 或 lower - 显示转小写命令
  • s 或 search - 显示搜索命令
  • c 或 copy - 显示复制命令

💡 使用技巧

  • 直接按 Enter 执行第一个建议
  • 使用 Tab 自动补全命令
  • 按 Esc 隐藏建议框
  • 鼠标悬停在建议上可以预览
  • 点击建议直接执行
