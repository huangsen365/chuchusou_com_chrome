# 触触搜 v1.6.35 发布说明

发布日期：2026-06-13

## 一句话总览

**新增 X（推特）搜索** —— 选中文字 → 一键跳 X 站内搜索，与百度、Google 并列。

## 主要更新

### ✨ 新功能

#### X（推特）搜索

搜索分组新增「X（推特）搜索」（图标 𝕏）：选中网页文字、或没选时用页面关键词，点击即跳转 `https://x.com/search?q=关键字`。右键菜单、Popup 弹窗、侧边栏三个入口一致出现；选中文字时第一次右键即显（走 v1.6.34 的选区孪生树机制）。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **改动范围**：菜单配置（`unifiedMenuConfig.json` 及其镜像）+ 菜单构建/标题定义的 6 个枚举镜像点。不动 storage schema、消息协议、后台逻辑。

## 已知限制

- 语音选引擎暂不支持说"X / 推特"触发（语音为默认关闭的实验功能，本版未纳入）。
- 沿用前版已知限制（Grok 偶发换行闪烁等）。

## 升级提示

- 从 v1.6.34 升级：商店推送后自动更新即可
- 主观感受：右键 / Popup / 侧栏的搜索分组里，百度、Google 之后多出「𝕏 X（推特）搜索」一项

完整商店描述沿用 v1.6.20 大版本（本版仅新增一个搜索项，无 UI 结构改动、无新权限）。
