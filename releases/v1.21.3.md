# 触触搜 v1.21.3 发布说明

发布日期：2026-11-05

## 一句话总览

**封面生成器跟进 ChatGPT Images 2.6。**

## 主要更新

### 🔧 改进

#### 文案跟进 ChatGPT Images 2.6

ChatGPT 的图像生成已升级到 Images 2.6，扩展里所有面向用户的「ChatGPT Images 2.5」都改为 2.6：

- 扩展名称与描述（扩展管理页、商店）
- 封面生成的引擎名（右键菜单、Popup、侧边栏）
- 欢迎页、README

#### 侧边栏「💡 不知道填什么？(2)」搜索词更新

自定义封面风格旁的第二个帮助按钮会跳 Google 搜社区提示词。原来搜的还停在「ChatGPT Images 2.0 提示词」，现在改为「ChatGPT Images 2.6 提示词」。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- 引擎 id `chatgpt-images` 不变，置顶风格、默认引擎等已保存的设置不受影响
- **无新增权限**、无存储结构变化、无服务器依赖

## 已知限制

- 沿用 v1.21.2 已知限制
- 只改文案：封面仍通过 chatgpt.com 发送提示词，用的是 ChatGPT 当前提供的图像模型；封面风格提示词本身没有针对 2.6 调整

## 升级提示

- 升级后右键菜单、Popup、侧边栏里的封面引擎名显示为「ChatGPT Images 2.6」
- 商店名称随 manifest 改为「触触搜 - ChatGPT Images 2.6 封面生成器 / 多 AI 速答 / 提示词优化」；商店后台的详细描述如有写 2.5 / 2.0，需要手动改
