# 触触搜 v1.21.2 发布说明

发布日期：2026-11-02

## 一句话总览

**ChatGPT 把长提示词收成附件后，「注入X草稿 / 生成封面」也会出现。**

## 主要更新

### 🐛 修复

#### 改写提示词变成「Pasted text」附件后，长文按钮不出现

用 ChatGPT 做长文改写时，如果粘贴的提示词很长，ChatGPT 会把它收成一个「Pasted text」`.txt` 附件，消息里只剩一张附件卡片。扩展在用户消息里找不到改写模板，就不认为这是改写出来的长文，所以没有「注入X草稿 / 生成封面」。

现在：

- 改写模板消息后面紧跟一条或几条**只有附件**的消息，生成的长文照常出现按钮
- 只发了一条附件时，**打开附件预览**、确认里面是完整的改写模板后按钮才出现，不靠文件名猜。关掉预览后按钮保留
- 中间夹着普通追问或别的回复，就不再沿用更早的模板
- 同名附件、其它消息或其它会话的预览都不能冒充；切换会话后重新确认

#### 文章结尾没有句号时，按钮一直不能点

末篇文章最后一段如果不是以句号等句末标点结尾（比如以链接、引号外的短语收尾），按钮会一直不能点。现在结尾标点只用来判断同一轮里前面那篇是不是中途断掉的旧稿，末篇文章本身不再要求句号结尾。

以下情况按钮照样不能点：

- 内容还在生成中
- 正文太短，还没读到完整文章

### 🔧 改进

- 刚生成完、等待页面稳定时，按钮提示由「正在确认内容完整性」改为「正在等待内容稳定」

### 🛠 技术改动

- ChatGPT 附件识别（附件卡片、预览面板、去掉附件后的消息文字）集中在 `modules/chatGptDom.js`，ChatGPT 改版时只改这一处
- 附件的模板验证按会话、用户消息、附件序号和文件名绑定，附件或网址变化后重新验证
- 冒烟测试（真 Chrome）新增附件场景：模板加附件、多个连续附件、普通追问 / 其它回复切断来源、仅凭文件名不认、同名或其它会话的预览不能冒充、切换会话后重新验证、过短正文不可用、生成中禁用；无句号文章点击后能注入 X 草稿和生成封面

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖

## 已知限制

- 沿用 v1.21.1 已知限制
- 单独发送的附件需要打开一次预览，扩展才能确认它是改写模板

## 升级提示

- 升级后**已打开的 ChatGPT 页面需要刷新一次**，之前没出按钮的附件改写长文才会出现「注入X草稿 / 生成封面」
- 商店描述沿用 v1.21.0
