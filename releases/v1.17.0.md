# 触触搜 v1.17.0 发布说明

发布日期：2026-09-20

## 一句话总览

**改写稿每篇轮换 3 个可借用的细分学科（60 个池），概念借用尺度按篇轮换** —— 概念来源不再被一份静态清单框死，也不再被「只用素材原词」框死。

## 主要更新

### ✨ 新功能

#### 每篇轮换一组可借用的学科

**背景**：静态学科清单每篇都完整摆在模型面前，它只会挑最熟的那几个（v1.14.3 因此砍掉了清单）；而 v1.16.0 的「只用素材原词、不引入任何外部术语」又走到了另一头，太死。这一版用计数器把两头接起来：清单要大，但每篇只看到一个**切片**。

- 内置 **60 个细分学科**，10 类 × 6，刻意拉开跨度：自然科学（物理 / 化学 / 生态 / 地质 / 气象 / 天文）、生命医学（免疫 / 神经科学 / 药理 / 营养 / 公共卫生 / 遗传）、工程技术（材料 / 交通 / 系统 / 软件 / 建筑 / 能源）、数学（概率统计 / 运筹 / 博弈 / 信息论 / 复杂系统 / 控制论）、社会科学（人类学 / 政治学 / 法学 / 语言学 / 传播学 / 教育学）、经济商业（金融 / 供应链 / 会计 / 组织行为 / 战略 / 营销）、人文（历史 / 哲学 / 伦理 / 宗教 / 考古 / 文学批评）、心理（认知 / 发展 / 社会心理 / 行为经济 / 学习科学 / 决策科学）、艺术设计（建筑 / 音乐 / 戏剧 / 视觉 / 产品 / 电影叙事）、实践领域（农业 / 烹饪 / 体育训练 / 军事 / 航海 / 项目管理）
- 每篇改写按计数取 **3 个**作为「本篇可借用的学科」，其余学科的概念本篇不用
- 索引 `((3n+i)×7) mod 60`，7 与 60 互质：**相邻两篇切片完全不重叠，20 篇轮完全池**；池按类分组、步长 7，**三个学科必来自三个不同类**
- **上一篇借用过的学科本篇自动列为「不借」**——由 n−1 直接算出，不存任何东西
- 切片替代 v1.15.0 的 12 项「第二视角」轴

模型拿到的是：

```
- 本篇可借用的学科（只在需要外部概念解释素材里的具体机制时借，每个借来的概念都要对应素材关键词表；其余学科的概念本篇不用）：信息论、传播学、市场营销；
- 上一篇借用过的学科，本篇不借：物理学、神经科学、系统工程；
```

**底座没变**：素材关键词表、特异性检验、近期概念记忆都在。切片只回答「要借的话从哪借」，不是「必须借」——讲农业的文章不会被硬塞法学概念。

#### 概念处理方式改为轮换借用尺度

四种方式全部允许借用，只轮换尺度，相邻两篇必不同：

- 以素材自己的词为主，最多从本篇允许借用的学科里借 1 个概念
- 以素材领域的术语为主，可借最多 2 个，每个都要对应关键词表里的具体机制
- 机制优先、命名从严：能用白话讲清楚的就不命名，借用不超过 1 个
- 允许借 3 个，但必须分别解释不同的机制，第一次出现时讲人话

**加粗上限仍固定「最多 6 个」，不轮换。**

### 🛠 技术改动

- `prompts/articleRewritePrompts.json` 与 `src/assets-json/` 双轨 `version: 25`（796 行）：`varietyPlan.disciplinePool` 60 条、`conceptModes` 改写、`secondLenses` 移除、`_comment` 更新映射；形式安排说明改为「概念以素材为准，需要外部概念解释机制时只能从本篇允许借用的学科里借」；二十八节加粗规则同步。
- `shared/rewriteVariety.js` + `src/shared/rewriteVariety.ts`：`SLICE_SIZE = 3`、`SLICE_STRIDE = 7`、`disciplineSlice(pool, n)`；`resolvePlan` 返回 `disciplines` / `excludedDisciplines`，`lens` 移除；`renderPlan` 新增两行。
- `verify:article-rewrite`：表规模 6 / 5 / 5 / 4 + 60 唯一池且 `secondLenses` 不得回流；n=0..200 相邻切片不重叠、`excludedDisciplines(n+1) === disciplines(n)`、每篇跨三类；20 篇覆盖全池；渲染两行与内置提示词两条新断言。冒烟已有的形式安排 / 近期概念断言不受影响。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化（复用 `ccs_rewrite_variety_counter`）、无服务器依赖、无新增站点匹配、无新增文件
- 长文页按钮的工作流识别标记未变

## 已知限制

- 沿用 v1.16.0 已知限制
- 切片是「允许借」不是「必须借」，素材本身不需要外部概念时模型可以一个都不借，属预期
- 池子改动后请保持 60 条并按类分组（每类 6 条），否则「三个学科来自三个不同类」不再成立；数量变化需同步测试里的 60

## 升级提示

- 从 v1.16.0 升级：形式安排里「如果素材允许，可以从「…」的角度补一个类比」那行换成了「本篇可借用的学科：A、B、C」和「上一篇借用过的学科，本篇不借：D、E、F」两行；概念处理那行不再要求「只用素材原词」
- 想调整学科池，改 `prompts/articleRewritePrompts.json` 的 `varietyPlan.disciplinePool`（同步 `src/assets-json/` 镜像）
- 其余功能与 v1.16.0 一致
- **上架说明**：本版沿用 [releases/v1.16.0.md](./v1.16.0.md) 的「商店描述」段（其中「概念只从素材里来」仍然准确）与上架提醒，不新增描述。
