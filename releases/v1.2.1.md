# 触触搜 v1.2.1 发布说明

发布日期：2026-04-30

## 一句话总览

修复边栏关键字总是滞后/为空的老问题（sidepanel 现在主动到 active tab 拉实时选区）；提示词模板调优（封面三段式、速答中篇补排版）；修长期红的 CI lint。

## 主要更新

### 🐛 修复

- **边栏关键字滞后/为空**（核心 bug）：sidepanel 是独立 page，不能注入 content script，原本只能吃 `selectedTextByTab` 缓存和 URL/title 兜底，所以选了文字边栏经常显示不出来或显示旧的。现在改为通过 `chrome.scripting.executeScript` 主动到 active tab 调 `window.getSelection()`，和右键菜单走同一条路径。Popup 同样开启 `forceFresh: true`。
- **点击边栏菜单项时仍可能用旧 keyword**：`handleClick` 和 `pinned.execute()` 在分发 `executeMenuAction` 之前 `await refresh()` 重新拉一次选区，避免开着边栏改选区后用旧值。

### 🔧 改进

- **封面生成器提示词**：模板从 `--要使用XX` 命令式改为「内容 / 风格 / 注意」三段式（带显式标签），ChatGPT Images 解析更稳；同时去掉模板里多余的"内容"前缀，直接用 `${input}`。
- **速答中篇回答补排版要求**：与长篇对齐 ——「合理分段，段间空行，提升阅读体验」。

### 🛠 技术改动

- 修长期红的 CI lint：`eslint.config.mjs` 补登 v1.2.0 加进来但漏注册的 11 个 SW 全局（`getEngineTitle` / `runAITaskByMenuId` / `applyTextLimit` / `tryOpenMenuUrl` / `AITaskRegistry` / `enforceFinalUrlCap` 等）。Service Worker 走 `importScripts()` 共享全局作用域，ESLint 不懂这个机制，每次加新模块都要在 config 里手动声明。
- `package.json` / `package-lock.json` 版本号同步到 1.2.1（之前长期停留在 1.0.0）。

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 无破坏性改动，旧用户升级直接生效

## 已知限制

- `chrome://`、扩展商店、PDF 内置查看器等页面仍然不让 `executeScript`，这种 tab 边栏只能拿 URL/title 兜底（和右键菜单一样的限制，浏览器规则绕不过）
- 用户必须先在 active tab 里有选区，边栏才能"看见"它

## 升级提示

老用户从 v1.2.0 升级 → 直接用即可，主要感知是：
1. 边栏侧边的关键字显示更准、更及时
2. 速答中篇回答会自动分段，长内容看起来不再是一坨
3. 封面生成器出图质量更稳
