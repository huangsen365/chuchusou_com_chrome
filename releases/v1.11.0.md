# 触触搜 v1.11.0 发布说明

发布日期：2026-08-30

## 一句话总览

**X 长文速答两处操作栏都能点，长文改写换成单句成段的移动端轻阅读排版** —— 找按钮不用来回翻，改写出来的稿子在手机上读着更轻。

## 主要更新

### ✨ 新功能

#### X 长文速答按钮在两处操作栏都会出现

一篇 X 长文页面上其实有**两条操作栏**：文章正文自带的那条，和外层帖子的那条。此前触触搜只在其中一处注入闪电入口，你滚到另一处就找不到按钮，得往回翻才能点到。

现在两条操作栏都会挂上按钮。它们指向同一篇文章、共享同一份状态：在任意一个上点下去，两个按钮会同时进入加载动画，完成提示也同步；不会重复发起两次速答。引用推文里的操作栏依然会被排除，不会误注入。

普通推文（非长文）行为不变，仍然只有一个入口。

#### 长文优化改写改为「单句成段」的轻阅读排版

这是本版最明显的产出变化。此前提示词要求「段落要完整，不要短句流」，产出是有一定文字密度的密实段落；在手机上读长文时容易疲劳。

现在默认改成**一句话一个自然段**，段落之间保留空行：

- 多数段落控制在 **10～40 个汉字**，整体段落中位长度以 **20～25 字**为目标
- 保留约**一成 45～70 字**的完整解释段，用来交代必要的条件、因果或复杂机制，让节奏有短有长、不至于长度雷同
- 原则上不超过 70 字；一句话只承担一个主要判断或一层因果推进，包含两个可独立成立的判断就拆成两段
- 每个小标题下可以由多个单句段落连续展开：提出问题 → 给出判断 → 解释机制 → 补充案例或边界 → 收束并承接下一部分

#### 防碎片化的底线同步收紧

段落变短不等于可以写成口号。新提示词明确禁止把一句完整的话**拆成没有独立意义的残句**，也不允许为了制造金句堆砌孤立词组。收尾自检清单相应改写为：是否出现残句、是否还有超过 70 字且可以拆成两个完整句子的长段落、大多数段落是否只承担一个完整句子、中位长度是否落在 20～25 字、每个小标题下的单句段落是否形成了功能不同且衔接自然的连续论述。

### 🛠 技术改动

- 站点速答共享运行时新增**可选**适配器钩子 `findActionContainers(root)`（返回多个容器）；未实现该钩子的适配器自动退回原有的单容器 `findActionContainer(root)`。注入、状态恢复与去重改为按容器遍历，同一 `sourceKey` 的多个按钮状态统一更新。知乎适配器未做改动，行为不变。
- X 适配器新增 `findTweetActionGroups()`：同时定位文章内与外层帖子的 `role="group"` 操作栏，并排除引用推文中的操作栏；`findActionContainer()` 保留为「取首个结果」的兼容入口。TypeScript 与 legacy 生产脚本双轨同步。
- 改写提示词模板升到 `version: 19`（748 行）。`verify:article-rewrite` 新增 13 条新规则断言、6 条废弃规则反向断言，以及第二版参考稿的排版画像校验（单句段占比 > 99%、中位 20 字、p90 42 字、最长 71 字）；真实 Chrome 冒烟新增 X 长文双操作栏注入覆盖。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖、无新增内容脚本匹配
- 未删除任何菜单项或入口；右键菜单、Popup、侧边栏、知乎速答、Google Docs 改写行为均不变

## 已知限制

- 沿用 v1.10.1 已知限制
- 双操作栏识别依赖 X 页面的 `role="group"` 结构；若 X 改版调整长文页面结构，可能退回单入口（不会报错，只是少一个按钮）
- 新排版风格是提示词层面的约束，实际产出仍由 ChatGPT / Claude 决定，个别情况下可能不完全达标

## 升级提示

- 从 v1.10.1 升级：X 长文页面会看到**两个**闪电按钮（文章内 + 外层帖子），这是预期行为，不是重复注入
- **改写产出风格会明显变化**：新稿子是一句话一段、留白较多。如果你更习惯旧的密实段落风格，注意这一版起默认不再那样产出
- 其余功能与 v1.10.1 完全一致
