# 触触搜 v1.14.3 发布说明

发布日期：2026-09-20

## 一句话总览

**改写提示词去掉学科菜单，知识跟着素材走** —— 讲农业的文章不再硬套行为经济学，讲法律的文章不再硬套心理学效应。

## 主要更新

### 🐛 修复

#### 改写稿一律往心理学 / 经济学概念上靠

**症状**：v1.14.2 去模具化后，标题和结构散开了，但文章里冒出来的概念还是集中在「某某效应」「某某定律」这一类心理学 / 行为经济学术语，和素材领域无关。

**根因**：提示词第四节列了 21 个「可以引入的学科」——心理学、行为经济学、社会学、管理学、组织行为学、决策科学、博弈论、营销、战略、风险、统计、信息论、复杂系统……严重偏向商业 / 心理 / 决策。模型把清单当菜单，不管素材讲什么都从里面挑。

**现在**（提示词 v22）：

- 第四节 21 项清单整段删除，换成「**知识跟着素材走**」：素材属于哪个领域，就优先用那个领域自己的概念和术语，不把别的领域的概念硬套上来
- 领域只以大类举例（社会科学 / 自然科学 / 工程技术 / 医学生命 / 人文历史 / 法律制度 / 艺术设计），并明确包括「任何行业、手艺、运动或日常经验里沉淀下来的行话和判断方法」
- 点名警告：不要因为心理学、经济学、管理学的概念更容易想到、更容易显得「有深度」就默认从它们里面找——这是 AI 改写稿最常见的偏向之一
- 输出段「这些概念不限学科……」改为「这些概念跟着素材走……」；十五节「不必局限于行为经济学或统计学」改为「不必局限于某个学科」
- 「可以适当穿插书籍 / 理论 / 方法……」那份清单保留——那是知识的形式，不是学科菜单

### 🛠 技术改动

- `prompts/articleRewritePrompts.json` 与 `src/assets-json/` 双轨升到 `version: 22`（786 → 770 行）。改完剩余的学科名（心理学 4、经济学 2、行为经济学 1、管理学 1）全部只出现在反向语境里；统计学、博弈论、信息论等归零。4 个工作流识别标记与第十九节锁死句未动。
- `verify:article-rewrite`：版本 / 行数断言同步 22 / 770；新增 2 条「跟着素材走」正向断言、4 条反向断言（旧清单不得回流）。

## 升级提示

- 从 v1.14.2 升级：「选 A」改写的概念来源会随素材领域变化，不再集中在心理学 / 经济学；非商业 / 心理类素材的文章可能整篇不出现任何「效应」命名，属预期
- 建议配合 v1.14.2 的验收一起做：挑三个领域差别大的素材各走一遍「选 A」，看概念是否来自素材自己的领域
- 其余功能与 v1.14.2 一致
- **上架说明**：本版为提示词修复，不新增商店描述，沿用 [releases/v1.14.0.md](./v1.14.0.md) 的「商店描述」段与上架提醒。
