# 触触搜 v1.17.4 发布说明

发布日期：2026-09-21

## 一句话总览

**改写成品必须独立成文** —— 不再出现「原文说……」这类指向来源的表述，纠偏静默完成；速答短篇 / 中篇不再用「真正」。

## 主要更新

### 🐛 修复

#### 改写稿读起来像在点评一份读者看不见的材料

**症状**：一篇 3638 字的「选 A」成品里「原文」出现 5 次、「这句话」1 次，几乎每个小标题下第一句都是「原文说……」「原文把……」，然后开始评价：「原文说上当就代表智商低，这个判断有力量，但也过于绝对」。读者手里没有原文，文章成了对一份看不见材料的批改，主体性没了。

**根因**（在提示词自己）：
- 用「素材 / 原始素材 / 材料 / 原文」指代输入近 100 次，任务被定义成「改写一份素材」，模型自然写成「关于那份素材的文章」
- 第二十三节要求「不要默认素材观点正确……进行适当修正」，但没说修正过程不能进正文，模型就把批改过程摆给了读者
- 全篇 800 行没有一句「成品不得提及素材的存在」

**现在**（提示词 v29）：
- 第二十三节改为「允许纠偏，但成品必须独立成文」：**静默纠偏**——直接写出修正后的判断作为文章自己的观点，不写「原文说 X，但 X 过于绝对」；**独立成文**——正文不得出现「原文 / 素材 / 原始材料 / 这段话 / 这句话 / 上文 / 作者说 / 题主 / 楼主」，也不用「这个观点 / 这个说法」指代素材本身；素材的观点直接作为文章自己的判断陈述，原话作为文章自己的句子出现；通篇不应有任何一处让读者意识到它是改写来的
- 第二十五节「最终效果」加 **独立成文**；第二十六节自检加「是否出现指向来源的表述，或把纠偏过程写了出来」
- 开头形式「素材里最有信息量的事实、数字或原话」注明「作为文章自己的句子写出来，不加「原文说」」

#### 速答短篇 / 中篇还在冒「真正」

去「真正」化（v1.14.2）只做在长文改写模板上；实测短篇第一句「真正厉害的创业者……」，中篇两次。短篇是直接当推文发的，比长文更显眼。速答模板新增「用词与独立性要求」：「真正」全文不用；短篇不用「不只是」「不是……而是……」对比句式；三种回答同样独立成文，不得出现指向来源的表述。
