# 触触搜 v1.6.4 发布说明

发布日期：2026-05-12

## 一句话总览

SEO 文案修正：`ChatGPT Image 2.0`（单数）→ `ChatGPT Images 2.0`（复数，对齐 OpenAI 官方品牌名），并删除引入的冗余括注 `（ChatGPT Images）`。**ZIP 内容与 v1.6.3 功能完全一致**，无代码改动。

## 主要更新

### 🔧 改进

#### manifest `name` 统一改为「ChatGPT Images 2.0」

老 name（v1.6.2/v1.6.3）：`触触搜 - ChatGPT Image 2.0 封面生成器 / 多 AI 速答 / 提示词优化`

新 name：`触触搜 - ChatGPT Images 2.0 封面生成器 / 多 AI 速答 / 提示词优化`

#### manifest `description` 统一为复数并删除冗余括注

老 description（v1.6.2/v1.6.3）：`基于 ChatGPT Image 2.0（ChatGPT Images）的封面生成器（小红书 / 椰树牌 / 二次元可爱 / 极简留白）+ 多 AI 速答 + 文本快速搜索处理`

新 description：`基于 ChatGPT Images 2.0 的封面生成器（小红书 / 椰树牌 / 二次元可爱 / 极简留白）+ 多 AI 速答 + 文本快速搜索处理`

**为什么改**：
- `ChatGPT Images` 是 OpenAI 官方品牌写法（参考 https://chatgpt.com/?prompt=...），原 v1.6.2 用「Image」是想兼容用户搜索习惯，但实测 Chrome Web Store 搜索是模糊匹配，复数形式仍能命中「ChatGPT Image」前缀搜索
- 同步删除冗余括注 `ChatGPT Images 2.0（ChatGPT Images）`——括号内外现在是同义重复，释放 132 字符 description 配额（净省约 18 字符）

#### README / welcome / store-listing 同步

- `README.md` H1、引导块、功能描述段全部对齐
- `welcome/welcome.html` tagline 对齐
- `releases/store-listing.txt` 模板对齐（[1] Name / [2] Short / [3] Detailed / [4] What's New 全部覆盖）

#### `package.json` description 对齐

同步把 `ChatGPT Image 2.0` 改为 `ChatGPT Images 2.0`，便于 GitHub Topics / NPM Registry / 第三方扫描器索引到统一关键字。
