# 触触搜 v1.4.0 发布说明

发布日期：2026-04-30

## 一句话总览

新增首次安装欢迎页（含视频教程 + 作者关注）+ AI 检测规避提示双层引导（欢迎页警告卡片含闪耀动画 + 顶部滚动横条点跳锚点 + 侧边栏 banner 文字横向滚动）；popup 底部 footer 改 `position: fixed` 短屏不再滚走；后台关键字提取加启发式兜底，未硬编码搜索引擎也能拿到关键字。

## 主要更新

### ✨ 新功能

- **首次安装欢迎页**（核心新功能）：
  - 装好扩展自动弹欢迎页（仅 `reason === 'install'` 触发，更新不打扰老用户）
  - 介绍**四种入口**：📑 侧边栏（推荐）/ 🪟 悬浮面板 / 🖱 右键菜单 / ⚡ Popup 弹窗
  - 「✨ 立即打开侧边栏」按钮在用户手势上下文调 `chrome.sidePanel.open()`，解决新用户"装了扩展找不到侧边栏"的痛点
  - 主打功能列表 + 🎥 视频教程（YouTube 缩略图，缩略图加载失败时优雅降级）+ 👋 关注作者（X/Twitter）

- **AI 检测规避提示双层引导**（封面生成器配套）：
  - **欢迎页 ⚠️ 警告 section**：amber 渐变卡片，三段式讲透"为什么生成图后要截图另存"——元数据指纹机制（C2PA 等）/ 平台识别后果（流量限流·推荐降权·强制水印·影响商业合作）/ 截图为何有效（新文件不带原指纹）+ 截图快捷键脚注
  - **闪耀动画**：边框 amber 光晕脉冲（2.6s/loop）+ 斜向白光带每 4 秒从左到右掠过——主动吸引视觉注意
  - **顶部滚动横条**（amber 横条，整条可点击）：「图片生成后，建议截图另存新图再使用，避免被识别为AI产出 · 点击查看详情 →」从右到左滚动 20 秒/loop，hover 暂停。点击通过 `scroll-behavior: smooth` 平滑滚到下方详细 section

- **侧边栏 banner 文字横向滚动**：
  - 原静态「⚠️ 图片生成后...」改为 18 秒/loop 从右往左滚动（≈27px/秒，可读速度）
  - 悬停整行（包括悬停 ⚠️ 看 popover）时 `animation-play-state: paused` 暂停，方便用户读完
  - 被动捕获视线，比静态文字命中率高得多

- **未硬编码搜索引擎也能拿关键字**：
  - `background/keywords.js` 20+ 个硬编码 hostname 分支（百度 / Google / Bing / 微博 / B站 / 知乎 / 淘宝 / ChatGPT / Claude / Grok 等）保留不动作快通道
  - 全 fall-through 后调启发式 `heuristicExtractFromParams()` 兜底打分：命中常见 key 名（q/query/search/s/kw/keyword/wd/word/p/text/k/searchword）+10 / 长度封顶 +5 / 含中文 +3 / 像 URL 或 UUID 直接 -100 / 纯数字短值 -5
  - PARAM_BLACKLIST 过滤 utm_*、ref、fbclid、gclid、tbm、hl、source 等噪声参数
  - 启发式命中后打 BG_DBG 日志含 hostname/key/score，方便日后从真实数据反向把高频未硬编码引擎加入硬编码

### 🐛 修复

- **popup 底部 footer 短屏被滚走**：
  - 之前问题：分辨率低 / 浏览器窗口短的设备上，popup 内容超出可视高度时整个 popup 出外层滚动条，「📑 打开侧边栏」按钮要滚到底才能看到——很多用户根本找不到
  - 修复：footer 改为 `position: fixed; bottom: 0; left: 0; right: 0; z-index: 100`，钉在 popup 视口底部；body 改为 `overflow-y: auto` 自身做 scroll container；popup-menu 加 `padding-bottom = footer 高度` 避免最后一项被盖
  - 跨设备稳定贴底，**不依赖 vh / dvh / JS innerHeight 同步**（这些路线踩过坑详见 docs/archive/POPUP_FOOTER_STICKY_SHORT_DISPLAY.md）

### 🔧 改进

- **AI 检测提醒文案精简**：「图片生成后，建议截图成新文件上传自媒体，避免被识别为AI生成」→「图片生成后，建议截图另存新图再使用，避免被识别为AI产出」。「另存新图」比「成新文件」更直观（图片场景），「再使用」语义比「上传自媒体」更广（覆盖所有使用场景）；窄边栏单行容纳更稳。
- **popup「打开侧边栏」按钮升级实心 amber 填充**：白字 + amber 实底 + 字重 600 + 阴影，hover/active 加深，让按钮成 footer 视觉焦点；footer 上方加轻阴影强化 sticky 边界。

### 🛠 技术改动

- 新增 `welcome/welcome.{html,css,js}` 三个文件，build.sh 把 `welcome/` 加入 `REQUIRED_FILES` + `COPY_DIRS`，发版 zip 不漏。
- popup CSS 抽出 `--ccs-popup-width` / `--ccs-popup-max-height` / `--ccs-popup-footer-height` 三个 token，避免散落魔法数。
- 所有动画（welcome 闪耀 / 顶部滚动横条 / sidepanel banner 滚动）都加 `prefers-reduced-motion` 媒体查询兜底——系统关动效用户自动停所有动画或显示静态版。
- 新增 `docs/archive/POPUP_FOOTER_STICKY_SHORT_DISPLAY.md`，归档 popup footer 短屏问题排查记录（5 条失败路线 + 最终 fixed footer 方案 + 死结分析），避免后续 AI / 维护者重蹈覆辙。

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 无破坏性改动，旧用户升级直接生效
- 老用户从 v1.3.1 升级**不会重弹欢迎页**（onInstalled 仅在 reason==='install' 时触发，update 跳过）

## 已知限制

- `chrome://contextual-tasks/`（Chrome 内嵌 Google AI Mode 的内部协议页）关键字暂不识别（详见 docs/KNOWN_ISSUES.md），鼠标选区无法捕获——Chrome 平台层硬限制
- 欢迎页 YouTube 缩略图加载需访问 `img.youtube.com`，大陆用户可能加载失败（已做 onerror 优雅降级，露出 CSS 深色背景 + 红色播放按钮，按钮仍可点击跳转 YouTube）
- 启发式关键字提取仅作未硬编码引擎兜底，对极少数参数命名异常的搜索站可能选错 param（实际跑日志后可反向把高频站固化到硬编码）

## 升级提示

老用户从 v1.3.1 升级 → 主要感知：

1. **不会重弹欢迎页**（仅首次装才弹）
2. **侧边栏置顶区下方的 ⚠️ banner 文字现在从右往左滚动**（鼠标悬停可暂停读完，⚠️ 上 hover 仍能看完整 popover）
3. **popup 底部「📑 打开侧边栏」按钮升级为实心 amber 填充**，更显眼；短屏下永远在 popup 底部不会被滚走
4. 未硬编码的搜索引擎页面现在也能拿到关键字（之前只能用页面 title 兜底）
