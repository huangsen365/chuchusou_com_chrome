# v1.0.0 - MVP 版本

**发布日期**: 2024-08

## 新功能

### 核心功能
- 实现文本选中检测和悬浮框显示
- 支持 10 个常用功能按钮
- 实现本地命令系统
- 添加基础 Popup 页面

### 快捷按钮（悬浮菜单）
- 百度搜索
- Google 搜索
- 复制文本
- 剪切文本
- Base64 编码/解码
- URL 编码/解码
- 转换大小写
- MD5 哈希

### 命令系统
- `/base64 文本` - Base64 编码
- `/base64 -d 编码文本` - Base64 解码
- `/md5 文本` - 生成 MD5 哈希
- `/url 文本` - URL 编码
- `/url decode 编码文本` - URL 解码
- `/upper 文本` - 转换为大写
- `/lower 文本` - 转换为小写

## 技术特点
- Manifest V3 标准
- Shadow DOM 样式隔离
- 纯原生 JavaScript 实现
