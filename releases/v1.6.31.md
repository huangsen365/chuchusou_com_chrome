# 触触搜 v1.6.31 发布说明

发布日期：2026-06-09

## 一句话总览

**封面生成器默认风格从「🔴 小红书封面」改为「⬜ 极简的留白」**（`minimal`），首屏更干净、留白更克制。

## 主要更新

### 🔧 改进

#### 封面默认风格 = 极简的留白

**改动**：新装用户首次打开封面生成器时，默认勾选的风格从「🔴 小红书封面」(`xiaohongshu`) 改为「⬜ 极简的留白」(`minimal`)。三个入口一致：

- 侧边栏封面 picker 的默认勾选
- popup 上的封面快捷启动卡片
- 右键菜单封面项的 fallback 风格

**对老用户的影响**：**无**。这只是「默认值」，仅在用户从未手动 Pin 过任何风格（全新安装 / 存储为空）时生效。已经手动选过某个风格的用户，存储里有值，不会被本次改动覆盖。

## 兼容性

- Chrome 114+（不变）
- Manifest V3
- 用户已有数据全部兼容（含已 Pin 的封面风格、自定义风格、比例预设）
- **改动范围**：封面默认值 6 处同源 + 重新生成 popup/sidepanel bundle。不动 storage schema、不动菜单结构、不动菜单消息协议。

## 已知限制

- **Grok 偶发换行闪烁**：Lexical reconciler 在插入后 100-500ms 内偶尔 revert，多轮校验覆盖大部分但非 100%。
- **文心一言（百度）偶发提交后提示词驻留**：已加用户清空检测，但仍有边界场景；后续版本继续跟进。
- Google AI 模式因 URL 长度上限，超长提示词仍可能被截断，已通过 relay 缓解。

## 升级提示

- 从 v1.6.30 升级：商店推送后浏览器自动更新即可
- **新装用户**：首次打开封面生成器看到的默认风格是「极简的留白」
- **老用户**：之前手动选过的封面风格、自定义风格、比例预设全部保留，不受默认值改动影响

完整商店描述沿用 v1.6.20 大版本（本版为 patch：仅封面默认值微调，无 UI 结构改动、无新功能、无新菜单项）。
