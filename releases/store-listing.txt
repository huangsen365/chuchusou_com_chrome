[3] ★ 详细描述（Detailed description）  上限 16000 字符
---------------------------------------------------------
触触搜——把"选中文本"变成"调用 AI 的入口"，让 AI 能力像系统级功能一样嵌入你的浏览过程。

🎯 四种入口，覆盖所有使用场景
─────────────────────────
• 🖱️ 悬浮浮窗：选中文字自动出现，快速操作不打断阅读
• 🖱️ 右键菜单：选中后右键，全部功能任你选
• 🪟 Popup 弹窗：点扩展图标，没选中文字也能用（输入关键字 / 改设置）
• 📑 侧边栏：Alt+S 召唤，长时间创作 / 反复用同一动作

四种入口共享同一菜单结构，体验完全一致。

⚡ 速答壹拾佰：一题多 AI 对比 · 智能两步流程
─────────────────────────
选中任意主题，一键发送给 ChatGPT、Claude、Grok、文心一言、Google AI Mode 五家。
两步流程模板：
  1. 先输出"短篇（80 字内带标题感）+ 中篇（约 10 句）"
  2. 末尾追加 A/B 两选项 —— A 续写长篇正文（无追问，便于复制使用），B 把短/中篇润色为更自然的真实表达

💯 触触搜百问：避免单一模型偏见
─────────────────────────
同一主题一次性问遍五大 AI，多视角对比，避开单家模型的盲区。

🧠 优化提示词：八种场景一键升级
─────────────────────────
内置八类场景模板（深度研究 / 普通对话 / 代码编写 / 内容创作 / 数据分析 / 问题解答 / 头脑风暴 / 描述润色），自动用提示工程最佳实践重写你的问题。

🎨 封面生成器（v1.2.0+ 持续迭代）
─────────────────────────
选中标题/段落 → 一键调用 ChatGPT Images 2.0 → 渲染封面图。

预设风格：
  • 🔴 小红书封面（颜色：黄/绿/蓝/红 随机搭配）
  • 🥥 椰树牌风格

自定义风格预设库（v1.5+）：
  • 多行编辑，每行=一个独立预设
  • dropdown 切换当前应用，随时切换"莫兰迪 / 极简 / 胶片 / 日杂..."
  • 跨会话持久化，下次打开记住你的所有预设

比例选择（10 个预设覆盖国内外主流自媒体平台）：
  • 5:2 横幅封面（默认） · 2.35:1 微信公众号头图 / 电影宽屏
  • 2:1 横幅卡片（Twitter / 知乎） · 16:9 通用横屏（YouTube / B 站 / 视频号）
  • 3:2 头条号 / 摄影标准 · 4:3 传统媒体 / PPT
  • 1:1 方形（Instagram / 微博 / 朋友圈） · 4:5 竖版图文（Instagram）
  • 3:4 竖版封面（小红书原生 / Pinterest） · 9:16 手机竖屏（抖音 / TikTok / Reels / 视频号）
  • 不够用？支持自定义比例（如 21:9 / 1.43:1）

📑 侧边栏置顶（v1.2.0+）
─────────────────────────
把最常用的动作钉在侧边栏顶部，下次开侧边栏一键直达。
"✏️ 修改"按钮一站式编辑：风格 / 自定义预设 / 比例。

🛡️ 内容平台合规提示（v1.4.0+）
─────────────────────────
封面生成器配套贴心提示：解释元数据指纹机制 + 截图另存的工作原理 + 平台后果（限流 / 降权 / 强制 AI 水印 / 影响商业合作），帮你规避自媒体平台的 AI 内容检测。

📋 剪贴板兜底（v1.5.1+）
─────────────────────────
chrome://、扩展商店等不允许 content script 注入的页面，侧边栏顶部自动显示"从剪贴板读取关键字"按钮 —— 复制文字后点一下即可走通完整流程。

👋 首次安装欢迎页（v1.4.0+）
─────────────────────────
装好扩展自动弹欢迎页，介绍四种入口 + 主打功能 + 视频教程。"立即打开侧边栏"按钮一键体验，关掉后想再看可在 ⚙️ 设置 → "查看欢迎页" 找回。

🔍 搜索引擎一键达
─────────────────────────
自动从选中文本/URL/标题智能提取关键词，一键跳转：
  • 综合：百度、Google、知乎、微信搜一搜、V2EX
  • 电商：淘宝、京东
  • 翻译：百度翻译、Google 翻译
  • AI：ChatGPT、Claude、Grok、文心一言、Google AI Mode
未硬编码搜索引擎也能拿关键字（v1.4+ 启发式参数提取兜底）。

🛡️ 隐私优先
─────────────────────────
• 所有选中文本本地处理，只在你点击具体功能时才发送到目标 AI 服务
• 不收集任何用户数据，不上传服务器
• 完整开源，代码可审

⚙️ 技术规格
─────────────────────────
• Manifest V3，Service Worker 架构
• 资源占用极低（安装包 ~250KB）
• 支持 Chrome 114+

---------------------------------------------------------
[13] ★ 权限说明（Permissions Justification）
     审核会逐项问，逐条填好
---------------------------------------------------------
activeTab：
  读取当前标签页 URL 和标题，从中智能提取关键词作为搜索备选词。

contextMenus：
  在浏览器右键菜单中添加"触触搜"主菜单及其子菜单（搜索、AI 对话、工具命令等）。

storage：
  使用 chrome.storage.local 保存用户偏好：黑名单网站、调试日志开关、
  侧边栏置顶动作、自定义风格预设库、比例选择、自定义提示词库等。
  仅本地存储，不上传服务器。

scripting：
  当 content script 因页面卸载等原因失联时，主动重新注入兜底，确保功能稳定。

clipboardRead：
  在用户主动触发"复制""Base64 编码"等命令时读取剪贴板内容；
  v1.5.1+ 在 chrome:// 等不支持选区的页面，用户可点"📋 从剪贴板读取关键字"按钮兜底。

clipboardWrite：
  把命令系统的处理结果（编码后文本、提示词等）写入剪贴板，方便用户粘贴。

sidePanel：
  提供 Chrome 侧边栏入口，置顶快捷动作、AI 任务一键直达。

host_permissions <all_urls>：
  扩展核心价值是"在任何网页选中文本即用"，因此需要在所有 URL 上注入 content script。
  插件不收集任何页面数据，仅在用户主动操作时读取选中文本。
