# 触触搜 v1.14.0 发布说明

发布日期：2026-09-18

## 一句话总览

**「✒️ 墨清风格」成为封面生成器的默认置顶风格** —— 新用户一打开侧边栏就是它；已经选过风格的老用户不受影响。提示词基调改为「明亮一点」。

## 主要更新

### ✨ 新功能

#### 封面生成器默认置顶风格改为「墨清风格」

此前默认置顶是「极简的留白」。从本版起：

- **新装用户**、以及**从没在侧边栏 ✏️ 里改过置顶**的用户，打开侧边栏看到的置顶动作就是「✒️ 墨清风格」，右键 / Popup 的封面菜单顺序不变
- ChatGPT 长文页的「生成封面」在没有置顶时也用墨清风格兜底；置顶了别的风格仍跟随置顶（v1.13.0 行为）
- **已经保存过置顶的老用户完全不受影响**，仍是自己选的那个；想换成墨清在 ✏️ 里点一下即可
- 极简留白 / 小红书 / 椰树牌 / 二次元可爱 / 自定义都还在，随时可切

### 🔧 改进

#### 「墨清风格」提示词基调改为「明亮一点」

v1.13.2 加的那句「原则上看到都是有好心情」改为「原则上明亮一点」——对配色与氛围的约束更直接。版式规则（左上三行大标题、右侧竖排副标题、底部横排副标题、副标题字号为主标题一半、主副标题不重复）一字未动。

### 🛠 技术改动

- 默认风格 SSoT：`src/shared/coverPinConstants.ts` `DEFAULT_PIN = { taskId: "cover", categoryId: "zhumoqing" }`；`popup/popup.js`、`sidepanel/sidepanel.js`、`sidepanel-v2/sidepanel.js` 三份 legacy 字面量同步（无法 import，由 `verify:cover-consistency` 锁定逐字一致）。
- `background/articleActions.js` `COVER_DEFAULT_CATEGORY = 'zhumoqing'`，与 SSoT 同步；`modules/longArticleActions.js` 按钮 tooltip 更新。
- 测试：`verify:long-article-actions` 7 场景默认值断言 → `zhumoqing`，「跟随置顶」场景改置顶 `xiaohongshu`；冒烟长文封面默认值断言 → `zhumoqing`。
- `prompts/coverPrompts.json` 双轨 `zhumoqing.purpose` 改一句。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖、无新增站点匹配
- 已保存的置顶（`ccs_sidepanel_pinned_action`）、自定义预设、比例全部沿用，不做迁移
- 未删除任何菜单项或入口

## 已知限制

- 沿用 v1.13.2 已知限制
- 默认值只影响「没有保存过置顶」的用户；老用户若想统一切到墨清需手动在 ✏️ 里选一次（本版刻意不覆盖用户已保存的偏好）

## 升级提示

- 从 v1.13.x 升级：**如果你从没动过侧边栏 ✏️**，升级后置顶会从「极简的留白」变成「✒️ 墨清风格」，长文页「生成封面」也随之变为墨清版式——这是预期行为；想回极简在 ✏️ 里切回即可
- 如果你之前手动置顶过任何风格，什么都不会变
- 其余功能与 v1.13.2 一致
