# 触触搜 v1.18.6 发布说明

发布日期：2026-09-25

## 一句话总览

**「选A改写」生成的长文恢复主标题与小节结构** —— 同时修复后台标签页按钮不重建、右键菜单图标探测结果不持久化，并完成一轮不改变功能的内部重构。

## 主要更新

### 🐛 修复

#### 速答后「选A改写」的长文没有标题、没有分节

速答第一轮提示词规定：用户选 A 时，把约 100 句正文放进一个 writing block，块内「不得出现标题」。点「选A改写」时，这条规则仍留在对话上下文里，而改写提示词要求「# 主标题 + ## 小标题 + 正文」，两条要求互相冲突，模型按第一轮执行：

- 整篇是 100 多个单句段落连续排下去，**没有主标题，也没有任何小节**
- 文章被放进标签为「详细内容」的 writing block，「注入X草稿」会把「详细内容」当作标题

现在：
- 改写提示词第二十八节明确要求：**全文一个主标题放在最开头，正文按主线分成 3～6 个小节**，每节以小标题开头；并写明本轮**压过此前对话里的格式要求**（只放正文、不得出现标题、约 100 句等），无论是否使用 writing block 都必须写出主标题和小标题
- 最终自检加入「是否有且只有一个主标题、是否分成 3～6 个小节」
- 速答提示词的 A 规则加入例外：附带完整改写提示词时，篇幅、结构与排版以改写提示词为准
- 覆盖句写在改写模板里，**已经开着的老对话**再点一次「选A改写」同样生效；「选A并且按照提示词改写」开头与四个工作流识别标记保持不变

#### 后台标签页里的站点速答按钮不重建

浏览器在后台标签页不会触发 requestAnimationFrame。知乎、X、ChatGPT 页面处于后台时，操作栏被网站重绘后，扩展按钮要等切回标签页才补上。现在页面隐藏时改用定时器扫描，切回时按钮已经就位。

#### 右键菜单图标「不支持」的探测结果每次重启都丢失

右键菜单图标更新失败时，扩展会记下「不支持」并在之后跳过图标更新。但写入和读取用的存储键名不一致，记录从未生效，每次后台重启都会重试一遍图标更新并重复报错。现在读写同一个键。

### 🔧 改进

- **提示词正文改为 Markdown 文件**：`prompts/articleRewrite.md`、`fastAnswers.md`、`topQuestions.md`、`optimized.md`、`cover.md` 直接编辑，不用再处理 JSON 转义；对应的 `*Prompts.json` 只保留元数据并通过 `templateFile` 指向正文。运行时拼出的提示词与之前逐字相同。
- **安装包更小**：去掉从未启用的 popup / 侧边栏备用版、不会被加载的三个 popup 模块，以及构建时多出的 Plasmo 页面产物，安装包从约 720 KB 降到约 490 KB（解压后约 2.4 MB → 1.5 MB）。

### 🛠 技术改动

- **一份逻辑一个源**：删除 86 个从未上线的 TypeScript 平行实现（内容脚本、popup、侧边栏、静态页、SW 模块孪生版）与 `src/assets-json` 镜像；`src/` 只保留 SW 实际打包的 21 个模块。删除早已失效的 `background/index.js` 入口，manifest 直接指向 `static/background/index.js`。原双轨对比测试改为针对实际运行代码的 golden 快照测试（`scripts/fixtures/golden/`）。
- **SW 事件层按领域拆分**：`background/events.js` 只负责按原顺序注册监听；13 个领域文件放在 `background/events/`，runtime 消息改为分发表登记（重复登记在启动时报错）。逐行核对只有包装层变化。
- **站点适配器**：ChatGPT 输入框、发送 / 停止按钮、writing block 标题栏等选择器集中到 `modules/chatGptDom.js`；新增 `verify:site-adapters`，ChatGPT / X / 知乎 / Google Docs 选择器只能写在各自适配器里。
- **存储键注册表**：新增 `shared/storageKeys.js` 登记全部 `ccs_*` 键与前缀，在 SW、内容脚本、popup / 侧边栏里都第一个加载；新增 `verify:storage-keys`，未登记的键名直接报错。
- **新增守卫**：SW 各脚本顶层重名检测（发现并删除 3 处被静默覆盖的同名函数副本，运行行为不变）、`background/` 下不在加载列表的脚本检测；ESLint 的 SW 全局变量改为从加载列表自动收集。
- popup / 侧边栏合并脚本只在构建时生成，不再提交进仓库，生成失败会让构建失败；移除未使用的 React 依赖；冒烟测试两处计时抖动改为轮询等待。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖
- 新增内容脚本 `shared/storageKeys.js`、`shared/promptTemplate.js`（纯常量 / 读取扩展内提示词文件，无网络）

## 已知限制

- 沿用 v1.18.5 已知限制

- 从 v1.18.5 升级后，**已打开的 ChatGPT / 知乎 / X 页面需要刷新一次**才会加载新的内容脚本
- 已有的速答对话里，再点一次「选A改写」即可得到带主标题和小节的长文
- **上架说明**：本版为修复，沿用 [releases/v1.18.0.md](./v1.18.0.md) 的「商店描述」段与上架提醒。
