# 触触搜 v1.6.42 发布说明

发布日期：2026-07-17

## 一句话总览

**封面生成器风格重排（默认项前置）+ 封面一致性 CI 守卫** —— 列表第一眼看到的就是默认风格，三入口顺序、默认值全通道锁死一致。

## 主要更新

### 🔧 改进

#### 封面风格顺序调整为「极简的留白」优先

封面生成器的风格清单此前按 二次元可爱 → 小红书 → 椰树牌 → 极简的留白 排列，而置顶快捷启动的默认风格是「极简的留白」——默认用的排在第 4 位，第一眼看到的却不是默认，有认知错位。本版统一重排为：

1. ⬜ 极简的留白（默认）
2. 🔴 小红书封面
3. 🥥 椰树牌风格
4. 🌸 二次元可爱
5. 🖌️ 自定义风格（仅侧边栏风格选择器）

三个入口（右键菜单 / Popup / 侧边栏）读同一份配置，自动同步换序；右键菜单「🚀 打开以下全部预设风格」按新顺序开标签。扩展商店描述里的风格列举同步对齐。

### 🛠 技术改动

- **封面一致性 CI 守卫**（`scripts/verify-cover-consistency.mjs`，随 `npm test` / CI 自动跑）：
  - 风格清单 SSoT（`prompts/coverPrompts.json`）形态校验：id 唯一、label 非空、预设风格必有可打开的 URL 模板
  - 4 份标题表（背景 Constants ×2 + 菜单结构构建器 ×2）键集合与 SSoT 完全相等、值逐字一致、emoji + label 形态锁死
  - 默认风格（minimal）/ 默认比例（5:2）/ pin 存储 key 在 SW、popup、sidepanel、AITaskHandler 全通道逐字一致；11 个比例预设清单整体对齐
  - 新增/改名风格或改默认值漏改任意一处 → 本地 `npm test` 和 CI 直接红
- SW 右键置顶封面项（menuBuilderAttach.ts）的 pin 常量收敛到 `src/shared/coverPinConstants.ts` 单一来源；自定义字眼的兜底行为与侧边栏对齐（取第一个非空行）

## 兼容性
