# 触触搜 v1.18.10 发布说明

发布日期：2026-09-29

## 一句话总览

**小屏幕上，封面风格选择器的「取消 / 保存」不用滚动就能点到。**

## 主要更新

### 🔧 改进

#### 「取消 / 保存」贴底显示

在屏幕较矮的电脑上，侧边栏的置顶风格选择器（点 ✏️ 打开）比窗口还高，底部的「取消 / 保存」要往下滚才能看到。

现在：
- **按钮原位置还在窗口下方时**：「取消 / 保存」贴在窗口底部显示，带不透明底色和上沿一道淡阴影，打开选择器就能直接点「保存」
- **滚到按钮原本的位置时**：按钮行自动停回原位、阴影消失，随页面正常滚动；继续往下滚，就随选择器一起离开
- **屏幕够高、选择器一屏放得下时**：外观与之前完全相同

效果按窗口实际高度自动判断，拉高拉矮侧边栏、选择「自定义风格」后内容变长都会自动适应。

### 🛠 技术改动

- 按钮行使用 CSS `position: sticky; bottom: 0`；负外边距加内边距让停在原位时的布局逐像素不变；浮起时的阴影由按钮行原位底边的 1px 标记 + IntersectionObserver 切换。
- 冒烟测试把侧边栏压到 400px 高，在真 Chrome 里检查三种状态：不滚动即可见且带阴影、滚到原位停回、继续滚随选择器离开。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖
- 只改侧边栏风格选择器的按钮行，其它界面不变
