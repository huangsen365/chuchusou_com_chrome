# 触触搜 v1.6.8 发布说明

发布日期：2026-05-14

## 一句话总览

封面生成器子菜单顶部新增「🚀 打开以下全部预设风格」—— 一键开 4 个 tab，同时跑二次元可爱 / 小红书封面 / 椰树牌风格 / 极简留白 4 种内置风格，同一 ChatGPT Images 2.0 引擎、各自独立的 prompt，让"选风格"从串行变并行。**无破坏改动、无 storage schema 变化、无新依赖。**

## 主要更新

### ✨ 新功能

#### 封面生成器子菜单：「🚀 打开以下全部预设风格」

之前用户要在 4 种内置封面风格里挑最合适的，必须依次点 4 次「二次元可爱 / 小红书封面 / 椰树牌风格 / 极简留白」、每次等 ChatGPT Images 2.0 渲染、再回头切对比。v1.6.8 起，子菜单顶部直接有：

```
触触搜
└── 高级功能
    └── 🎨 封面生成器
        ├── 🚀 打开以下全部预设风格   ← 新增
        ├── ──────
        ├── 🌸 二次元可爱
        ├── 🔴 小红书封面
        ├── 🥥 椰树牌风格
        └── ⬜ 极简的留白
```

点击后**一次性开 4 个 tab**：
- 同一份选中文本（自动套用 sidepanel 设置的字数保护和最大长度）
- 同一个画面比例（5:2 / 6:2 / 9:16 等，sidepanel 设过即生效）
- 4 种不同风格 —— 每个 tab 注入对应 category 的 `${purpose}` 单独构造 prompt

行为与速答 / 百问 / 优化的「打开以下全部」对称，位置也一致（子菜单第一项）。

**为什么跳过「自定义风格」**：custom 依赖 sidepanel 输入框，批量场景无 `${purpose}`，开了也是空提示。代码里通过 `openAllSkipCategoryIds: ['custom']` 显式声明，避免误开。

#### 三端可见性

| 入口 | 支持「打开以下全部预设风格」 |
|---|---|
| 右键菜单 → 高级功能 → 封面生成器 | ✅ 子菜单顶部 |
| Popup → 高级功能 → 封面生成器 | ✅ 子菜单顶部 |
| Sidepanel sticky pin 卡片 | ⛔ 不变 |

sidepanel 不变的原因：sidepanel 的主菜单列表本来就只渲染 leaf 项（cover-root 带 children 被过滤），用户访问 cover 走 sticky pin 卡片那条独立通道；保持与速答/百问/优化在 sidepanel 上的行为一致。

### 🛠 技术改动

- **`AITaskRegistry` 引入 `openAllAxis` 语义**：
  - `'engine'`（默认）：速答/百问/优化沿 engine 轴批量 —— 一种 prompt × N 个引擎
  - `'category'`（cover）：cover 沿 category 轴批量 —— N 种 prompt × 同一个引擎
  - 声明式注册，未来加新任务直接选轴
- **`AITaskHandler.runAITask` 的 openAll 分支按 axis 分流**：category 轴时为每个 category 单独构造 prompt（注入自己的 `${purpose}`），共享一份字数保护、URL 上限、ratio 注入
- **`events.js` SSoT fast-path** 从 `AITaskRegistry.resolveMenuId` 解出 `parsed.openAll` 透传给 `runAITask`，popup 点击 `ccs-cover-open-all` 自动走批量路径
- **「自定义风格」批量打开跳过**：通过 `openAllSkipCategoryIds: ['custom']` 声明，未来加任何"运行时依赖输入"的 category 直接加进去即可
- **右键菜单 `populateCoverMenus`** 仅当有效预设 ≥ 2 时才挂 open-all 项 + 分隔符（防止配置裁剪后只剩 1 个风格时显示无意义的"打开以下全部"）
- 改动文件：
  - `background/tasks/AITaskRegistry.js`
  - `background/tasks/AITaskHandler.js`
  - `background/menuBuilder.js`
  - `background/base.js`
  - `background/events.js`
  - `background/utils/Constants.js`

## 兼容性

- Chrome 114+（Manifest V3 + `chrome.sidePanel` API）
- 与 v1.6.7 完全兼容；无 storage schema 改动、无新依赖
- 老用户升级后看到的差异：
  - 右键菜单 → 高级功能 → 封面生成器子菜单顶部多一项「🚀 打开以下全部预设风格」
  - Popup 同样位置多一项
  - Sidepanel sticky pin 卡片不变

## 已知限制

- 一次性开 4 个 tab 会同时触发 4 次 ChatGPT Images 渲染，对配额敏感的账号请按需使用
- 跳过「自定义风格」是设计内行为；要用自定义风格请通过 sidepanel sticky pin 卡片或子菜单中的单条「自定义」入口（如启用）
