## 一句话总览

**速答回复末尾带来源列表时，「选A并优化改写」也会出现。**

## 主要更新

### 🐛 修复

#### 联网搜索过的速答回复看不到「↗ 选A并优化改写」

用「速答 → Claude」时，如果 Claude 联网搜索了，它会在 A/B 两行后面自己补一段来源：一行「Sources:」，下面是几篇参考文章的链接。扩展原来要求「B：」那一行必须是回复的最后一行，多出这段就不认这条回复，底栏的「Copy」后面也就没有「↗ 选A并优化改写」。

现在：

- A/B 后面跟着一段以来源标题开头的内容（Sources / References / Citations / 来源 / 参考资料 / 参考链接 / 参考文献等，标题后面是冒号或换行）也认，按钮照常出现
- A/B 后面是别的正文（比如「还想了解哪方面？」）仍不算速答回复，按钮不出现
- 这条规则 ChatGPT、Gemini、Claude 三站共用，哪家回复带来源都一样

### 🛠 技术改动

- 真机复核：在出问题的那条真实 Claude 回复上分别运行新旧两版识别规则——旧规则判定不匹配（与按钮不出现一致），新规则判定匹配
- 冒烟测试（真 Chrome）的 Claude 夹具新增「A/B 后带 Sources 列表 → 出按钮」「A/B 后还有别的正文 → 不出按钮」两个场景
- 单元测试覆盖：末尾 Sources 列表、中文「参考资料：」、同一行的「Sources: 链接」、来源前还夹着别的话（不认）、以 Sources 开头的普通单词（不认）
- 新增待调研文档 `docs/TO-BE-IMPLEMENTED/voice-command-routing.md`（语音指令选引擎，未实现，不进安装包）
