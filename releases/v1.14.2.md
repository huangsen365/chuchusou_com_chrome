# 触触搜 v1.14.2 发布说明

发布日期：2026-09-20

## 一句话总览

**「选 A」长文改写不再千篇一律** —— 标题不再默认长成「X：真正……，不只是……」，开头结尾不再同一套路，概念和方法论不再硬塞。

## 主要更新

### 🐛 修复

#### 改写稿同质化、标题频繁出现「真正」

**症状**：多位用户反馈，速答后「选 A」生成的长文一个模子：标题几乎都是「X：真正……，不只是……」，开头都是「你以为……其实……」，结尾都是「真正重要的不是……而是……」，每篇都要命名一个「效应」、给一套「判断方法」。

**根因**：在提示词自己身上，不是模型随机。改写提示词里「真正」出现 31 次，29 个章节标题里 5 个带它——包括直接管标题的那一节「标题要表达真正的核心矛盾」。模型读 8.5k 字指令会镜像它的用词和腔调。此外标题规则只给了「核心冲突 / 反常识」一个方向，开头只给了「让读者意识到和原来理解不一样」，结尾只给了「告诉读者真正重要的是什么」，并且强制每篇配概念标签、判断方法和 3～6 个加粗概念——四个模具叠在一起。

**现在**（提示词 v21）：

- 提示词自身语气里的「真正」31 → 0，5 个章节标题重写
- 新增输出禁用清单：「真正」全文最多 1 次且不进主标题 / 小标题 / 首段 / 末段；「不只是 / 不仅仅是 / 不是……而是……」标题禁用、正文最多 2 处；「本质上 / 底层逻辑 / 说到底 / 归根结底 / 换句话说」尽量不用；「你以为 / 别再」不作默认开头
- 标题 6 种形式（陈述判断 / 具体场景 / 问题 / 素材里的数字对比 / 核心概念 / 对比反常识），明确对比句和「主题：判断」冒号式最易同质化、只在素材本身是对比时才用；开头 5 种、结尾 5 种；标题、开头、结尾三处不得用同一手法
- 第二节固定的「看到现象 → 意识到理解不完整 → 发现问题 → ……」认知过程改为参考顺序，按素材决定叙事
- 判断方法只在素材有可操作经验时加，叙事 / 历史 / 人物类不硬加；素材没有成熟概念时整篇不出现「效应 / 定律 / 模型」命名也可以；加粗概念从「3～6 个」改为「最多 6 个，没有就不加」

### 🛠 技术改动

- `prompts/articleRewritePrompts.json` 与 `src/assets-json/` 双轨升到 `version: 21`（754 → 786 行）。禁用清单放在第三节末尾而非新开章节，避免重编号触碰内容脚本识别工作流所依赖的 `# 二十八、输出与排版要求` 等 4 个标记；第十九节（单句成段排版）锁死句一字未动。
- `verify:article-rewrite`：版本 / 行数断言更新为 21 / 786；新增 15 条去模具规则断言、6 条旧规则反向断言（如 `# 二十一、标题要表达真正的核心矛盾`、`全文挑出 **3～6 个**` 不得回流）；新增计数守卫——提示词里的「真正」只能作为引号内禁用词说明或反例出现（≤ 5 处），以后谁把它写回口头禅，CI 直接红。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖、无新增站点匹配
- 「注入X草稿 / 生成封面」按钮的工作流识别标记未变，长文页按钮行为不受影响
- 未删除任何菜单项或入口

## 已知限制

- 沿用 v1.14.1 已知限制
- 「≤ 1 次」这类计数约束由模型自觉执行，个别情况下可能仍会超出；若实测不稳，下一轮可改为「全文不得出现」
- 提示词只约束改写这一步，速答短篇 / 中篇的用词不在本次范围

## 升级提示

- 从 v1.14.1 升级：「选 A」改写的产出风格会明显变化——标题形式多样、不再必带「真正」和对比句，部分文章不再有「效应」命名和方法论段落。这是预期效果
- 建议用 3～5 篇不同题材的素材各走一遍「选 A」，看标题形式是否分散、叙事类素材是否还被硬塞方法论；有反例直接反馈
- 其余功能与 v1.14.1 一致
- **上架说明**：本版为提示词修复，不新增商店描述，沿用 [releases/v1.14.0.md](./v1.14.0.md) 的「商店描述」段与上架提醒。
