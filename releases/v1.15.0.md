# 触触搜 v1.15.0 发布说明

发布日期：2026-09-20

## 一句话总览

**长文改写按篇轮换标题 / 开头 / 结尾的形式，相邻两篇必不同** —— 用一个本地计数器给没有记忆的模型制造差异，连续写多篇也不再是一个模具。

## 主要更新

### ✨ 新功能

#### 改写稿的形式按篇轮换

**问题**：v1.14.2 / v1.14.3 给了标题 6 种、开头 5 种、结尾 5 种可选形式，但单次提示词没有跨文章记忆——模型每次都"自由选择"出同一种。连续写三五篇并排看，模具感还在。

**做法**：扩展在本地维护一个轮换计数器 n，每篇改写按 n 查表，把「本篇采用哪种形式」写成**具体指令**注入提示词，模型拿到的不是种子而是安排：

```
- 主标题采用「一个读者本来就会问的问题」的形式；
- 开头从「素材里最有信息量的一个事实、数字或原话」进入；
- 结尾用「说明这个结论的适用边界，或者留下一个还没解决的问题」收束；
- 如果素材允许，可以从「教育与学习」的角度补一个类比或解释；素材不允许就不补，不要为了用它而扭曲素材。
```

- 映射：标题 `n%6`、开头 `n%5`、结尾 `(n+⌊n/5⌋)%5`、第二视角 `(n×5+⌊n/12⌋)%12`。5 和 12 互质，**相邻两篇在四个轴上全部不同**；60 篇内标题与开头的组合不重复
- 计数器首次以「当天是一年中第几天 × 24 + 小时」为起点，不同用户从轮换周期的不同位置开始
- 第二视角 12 种（历史 / 生物医学 / 工程系统 / 法律制度 / 经济市场 / 心理行为 / 社会组织 / 艺术设计 / 数学统计 / 地理环境 / 教育学习 / 体育竞技）只是**可选补充**，明确写了「素材不允许就不补」——概念仍然只能来自素材，心理与经济各只占 1/12
- 6 / 5 两轴每 30 篇必有一次标题与开头撞同类手法（数学上不可避），模板补了一句：碰到就把开头换成相邻的另一种

对话内「选 A」与 Google Docs 改写两条路径都生效。

### 🛠 技术改动

- 新增 `shared/rewriteVariety.js` + `src/shared/rewriteVariety.ts`（1:1 对等）：`resolvePlan` / `renderPlan` / `apply` / `nextCounter` / `buildPlanText`；计数器 `ccs_rewrite_variety_counter`，周期 1800。已加入 `background/index.js` 与 `src/background.ts` 的 `importScripts` 列表（`verify:sw-bridge` 锁定一致）及 manifest 内容脚本（在 `articleRewriteRuntime.js` 之前）。
- 形式表在 `articleRewritePrompts.json` 新字段 `varietyPlan`，改文案不用改代码；模板 `version: 23`（776 行），`${varietyPlan}` 占位符恰好一个，4 个工作流识别标记未动。
- `background/events.js` 新增 `ccsBuildArticleRewritePrompt()`，两条路径共用；`modules/articleRewriteRuntime.js` 回退路径与 TS 口径同步，模板加载时校验占位符。
- 测试：`verify:article-rewrite` 新增 6 组断言（表规模 / 映射范围 / n=0..200 相邻互异 / 渲染格式 / 空计划兜底 / 日期种子）；冒烟在真 Chrome 里验证两条路径都带形式安排、无占位符泄漏，且紧接着的第二篇标题形式不同。修掉 `seedFromDate` 的跨 realm `instanceof Date` 与 `const d = … d?.getTime …` 自引用 TDZ 隐患。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无服务器依赖、无新增站点匹配
- 新增一个本地存储键 `ccs_rewrite_variety_counter`（一个整数）；新增一个内容脚本文件 `shared/rewriteVariety.js`（纯函数 + 本地计数，无 DOM 访问、无网络）
- 长文页按钮的工作流识别标记未变

## 已知限制

- 沿用 v1.14.3 已知限制
- 形式安排是提示词层面的指令，模型偶尔仍可能不完全遵守；素材本身不适合被安排的形式时，模板允许放弃
- 计数器是本地的，换设备或清除扩展数据后从日期种子重新开始

## 升级提示

- 从 v1.14.3 升级：「选 A」改写与 Google Docs 改写的标题 / 开头 / 结尾形式会按篇变化，连续几篇不再同形；部分文章会多一个来自第二视角的类比，属预期
- 想调整轮换的文案，直接改 `prompts/articleRewritePrompts.json` 的 `varietyPlan` 字段（记得同步 `src/assets-json/` 镜像）
- 其余功能与 v1.14.3 一致
