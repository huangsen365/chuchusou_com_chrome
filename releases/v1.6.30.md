# 触触搜 v1.6.30 发布说明

发布日期：2026-05-29

## 一句话总览

**封面生成器默认风格从「🌸 二次元可爱」改为「🔴 小红书封面」**，并随版本带上自 v1.6.29 后积累的 AI 提示词换行 / 长内容中转修复。

## 主要更新

### 🔧 改进

#### 封面默认风格 = 小红书封面

**改动**：新装用户首次打开封面生成器时，默认勾选的风格从「🌸 二次元可爱」(`anime-cute`) 改为「🔴 小红书封面」(`xiaohongshu`)。三个入口一致：

- 侧边栏封面 picker 的默认勾选
- popup 上的封面快捷启动卡片
- 右键菜单封面项的 fallback 风格

**对老用户的影响**：**无**。这只是「默认值」，仅在用户从未手动 Pin 过任何风格（全新安装 / 存储为空）时生效。已经手动选过某个风格的用户，存储里有值，不会被本次改动覆盖。

### 🐛 修复

#### AI 提示词填入保留换行

向 ChatGPT / Claude / Grok / 文心一言等 AI 编辑器填入多行提示词时，改用「native trusted 事件优先」的多级回退链路（insertHTML → 批量 insertText → 逐行 → synthetic paste → DOM 兜底），尽量保住换行结构，并在填入后多轮校验同步编辑器状态，减少被框架 reconciler 回滚导致的「换行丢失」。

#### 长查询 / 多行提示词走中转更稳

- 含换行或超长的提示词强制走 relay 中转页打开，避免直接拼到 URL 里被截断
- 修 Google AI relay 重定向被错误改写的问题
- 修长引擎查询 URL 的恢复逻辑

## 兼容性

- Chrome 114+（不变）
- Manifest V3
- 用户已有数据全部兼容（含已 Pin 的封面风格、自定义风格、比例预设）
- **改动范围**：封面默认值 6 处同源 + 重新生成 popup/sidepanel bundle；AI prompt fill 相关 `content.js` / `background/*` / `src/background/*`。不动 storage schema、不动菜单结构、不动菜单消息协议。

## 已知限制

- **Grok 偶发换行闪烁**：Lexical reconciler 在插入后 100-500ms 内偶尔 revert，多轮校验覆盖大部分但非 100%。
- **文心一言（百度）偶发提交后提示词驻留**：已加用户清空检测，但仍有边界场景；后续版本继续跟进。
- Google AI 模式因 URL 长度上限，超长提示词仍可能被截断，已通过 relay 缓解。

## 升级提示

- 从 v1.6.29 升级：商店推送后浏览器自动更新即可
- **新装用户**：首次打开封面生成器看到的默认风格是「小红书封面」
- **老用户**：之前手动选过的封面风格、自定义风格、比例预设全部保留，不受默认值改动影响
- 多行提示词填入 AI（ChatGPT / Claude 等）现在能保住换行

完整商店描述沿用 v1.6.20 大版本（本版为 patch：封面默认值微调 + AI 填入修复，无 UI 结构改动、无新功能、无新菜单项）。
