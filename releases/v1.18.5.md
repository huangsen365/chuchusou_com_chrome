# 触触搜 v1.18.5 发布说明

发布日期：2026-09-25

## 一句话总览

**适配 ChatGPT 页面改版** —— 「选A并优化改写」「注入X草稿 / 生成封面」按钮恢复正常，AI 填入不会再填进文章编辑器。

## 主要更新

### 🐛 修复

#### ChatGPT 改版后按钮识别失效、填入位置可能出错

ChatGPT 近期改了页面结构，触触搜依赖的几处识别随之失效：

- **一轮对话的结构变了**：旧版每条消息各自一个 `conversation-turn-*` 容器；新版一个 `data-turn-key` 容器里同时装着用户消息和助手回复，消息改用 `data-chatgpt-search-unit-key` 标识
- **writing block 换了标识，而且本身可编辑**：旧逻辑「页面上第一个可编辑区域就是输入框」在新版会命中文章编辑器，存在把提示词填进 writing block 的风险
- **聊天输入框移到了 `form[data-chatgpt-composer]` 里**，带 `data-composer-markdown`
- **新版操作栏**会把没有特殊标记的按钮压成 32px 图标宽度，扩展的文字按钮会被截断

现在：
- 新增统一的 ChatGPT 页面识别模块，**新旧两套结构都能识别**：消息角色、助手回复、所在轮次、正文、writing block、上一条用户提示词、复制按钮与动作栏插入位置
- 「选A并优化改写」和「注入X草稿 / 生成封面」都改用这个模块
- **AI 填入**在 ChatGPT 上优先定位聊天输入框，排除 writing block、消息节点、搜索框和隐藏节点，提示词只进聊天输入框，文章编辑器不受影响；已有草稿时照常提示并保留
- 扩展按钮带上新版操作栏的内容宽度标记，文字完整显示，窄栏时可换行

### 🛠 技术改动

- 新增 `modules/chatGptDom.js` 与 `src/content-modules/chatGptDom.ts`，manifest 内容脚本在 `articleRewriteRuntime.js` 之前加载；导出 `messageRole` / `messages` / `assistantMessageFor` / `turnFor` / `markdownFor` / `writingBlocks` / `previousUserMessage` / `responseCopyButton` / `insertAfterAction` 等。
- `modules/chatGptSelectARewrite.js`、`modules/articleRewriteRuntime.js`、`modules/longArticleActions.js`（及 TS 口径）改为依赖该模块。
- `content.js` / `src/content.ts`：ChatGPT 输入框选择器首选 `form[data-chatgpt-composer] [data-composer-markdown]`，候选排除 writing block、消息、`[role="search"]` 与 `[hidden]` / `[inert]` / `[aria-hidden="true"]` 内节点。
- 测试：新增 `scripts/lib/verify-chatgpt-redesign.mjs` 新版结构夹具，冒烟在真实构建上验证按钮嵌入、填写、长文来源与标题提取、生成状态及动作栏重建（夹具不访问线上会话）；`verify:ai-fill-ux` 覆盖新旧输入框定位、隐藏节点与草稿保护；`docs/TESTING_CHECKLIST.md` 补新版手测清单。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖
- 新增一个内容脚本文件 `modules/chatGptDom.js`（纯 DOM 查询，无网络）
- 旧版 ChatGPT 页面结构仍然兼容

## 已知限制

- 沿用 v1.18.4 已知限制
- ChatGPT 若再次调整页面结构，识别可能再度失效，届时需跟进适配

## 升级提示

- 从 v1.18.4 升级后，**已打开的 ChatGPT 页面需要刷新一次**才会加载新的内容脚本
- 其余功能与 v1.18.4 一致
- **上架说明**：本版为修复，沿用 [releases/v1.18.0.md](./v1.18.0.md) 的「商店描述」段与上架提醒。
