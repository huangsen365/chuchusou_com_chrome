# 触触搜 v1.6.28 发布说明

发布日期：2026-05-21

## 一句话总览

**封面提示词模板加 `#####CHUCHUSOU-START/END#####` 内容分隔符 + 超长内容降级提示**，让 AI 在用户正文含模板字眼时不再误解析，长文做封面时知道抽重点。

## 主要更新

### 🔧 改进

#### 1. 显式内容分隔符

之前的封面提示词模板长这样：

```
内容：
[用户选中的文本]

风格：
[purpose]
```

如果用户选中的正文本身就含有"风格："、"---"、"（以下仅供用户阅读）" 之类与模板结构碰撞的字眼，AI（ChatGPT Images 2.0）有时会**把这些当成模板的一部分**，结果生成的图片里会混进"内容"、"风格"这种字样，或者抓错"主标题"。

本版改为显式 fence：

```
内容（CHUCHUSOU-START和CHUCHUSOU-END之间）：


#####CHUCHUSOU-START#####

[用户选中的文本]

#####CHUCHUSOU-END#####
```

- 标题里点明边界 → AI 拿到的是"在这两个 marker 之间的就是内容"的强信号
- `#####CHUCHUSOU-START/END#####` 五个井号 + 自定义品牌 token，**几乎不可能**与用户正文重合
- 即使用户选中的文本含有 "风格：" / "---" / 中文括号等，AI 也能稳定切出内容区

#### 2. 超长内容降级提示

「注意：」段从

```
不要出现任何品牌名称或侵权素材
```

扩展为

```
不要出现任何品牌名称或侵权素材。如果内容过长，请酌情提取重点作为字眼
```

场景：用户偶尔会选 3000+ 字一整段文章去做封面，AI 之前会试图把全文塞到画面上，结果文字密密麻麻不像封面。现在 AI 明确知道"长文 → 抽 1-2 个核心词组当大标题"。

## 兼容性

- Chrome 114+（不变）
- Manifest V3
- 用户已有数据全部兼容
- **改动范围**：只有 `prompts/coverPrompts.json` 的 `templateLines` 数组；5 个 category 的 `purpose / engines` 完全不动；占位符（`${ratio} / ${input} / ${purpose}`）和 `AITaskHandler` 渲染逻辑零改动

## 影响面分析

| 入口 | 改动 | 行为 |
|---|---|---|
| popup → 封面菜单 | 提示词渲染后多包了两道 marker | 短内容生成质量持平或略好（边界更明确）；长内容明显更准（AI 知道抽重点） |
| sidepanel → 封面菜单 | 同上 | 同上 |
| 右键菜单 → 封面菜单 | 同上 | 同上 |
| 5 个 category（含 custom）| 共享同一份 templateLines | 全部受益 |

**没有副作用**：marker 只在 prompt 文本里出现，AI 已被指令明确告知"两 marker 之间是内容"，不会把 marker 本身画到图上。

## 升级提示

- 老用户升级后第一次用封面，体感差异不大但稳定性提升
- 选超长文做封面时，更不容易出现"画面塞满文字"的尴尬

完整商店描述沿用 v1.6.20 大版本（patch 仅调封面提示词模板，无新 UI 无破坏改动）。
