# 触触搜 v1.3.0 发布说明

发布日期：2026-04-30

## 一句话总览

封面生成器加上「AI 检测规避提示」—— 顶部 ⚠️ banner + 全宽悬浮说明卡，告诉创作者直接下载的图片自带 C2PA 指纹会被自媒体平台识别为 AI（建议截图成新文件），同口径文案也注入到 ChatGPT prompt 里做双保障；popup 按钮按当前状态切换显示「打开/关闭侧边栏」。

## 主要更新

### ✨ 新功能

- **AI 检测规避提示**（核心）：
  - 侧边栏 header 下方新增 ⚠️ 顶部 banner，文案 `图片生成后，建议截图成新文件上传自媒体，避免被识别为AI生成`（带「图片生成后」时间锚点，避免用户没生成图就觉得突兀）
  - 鼠标悬停 ⚠️ 弹出**全宽**悬浮说明卡，三段式讲透「为什么生成图后要截图成新文件」：AI 生成的图片下载时自带元数据指纹（C2PA 等）→ 自媒体平台一键识别 → 后果是流量限流 / 推荐降权 / 强制叠加 AI 水印 → 截图相当于重新存新文件不带原指纹
  - 卡片底部给出截图快捷键：`Mac ⇧⌘4 · Windows ⊞+Shift+S（或任意截图工具）`
  - 同口径文案同步追加到封面生成器的 ChatGPT prompt 末尾（带「以下仅供用户阅读，AI 请忽略本段」分区标记，避免 ChatGPT 把这段文字画到图里）—— 用户在对话流里也能再看到一次，双保障
- **popup 按钮按状态切换打开/关闭侧边栏**：以前不管侧边栏开没开都显示「📑 打开侧边栏」，点了没用还在原状态。现在按实际状态切换文案与行为 ——「📑 打开侧边栏」↔「📕 关闭侧边栏」，多窗口独立追踪（A 窗口的开关不影响 B 窗口）

### 🛠 技术改动

- **绕过 Chrome MV3 没有 `sidePanel.isOpen()` / `close()` API 的限制**：
  - background 加 `sidePanelPortsByWindow` Map，按 `windowId` 追踪活着的 port
  - sidepanel 启动时 `chrome.runtime.connect({name:'sidepanel-alive'})` 连 port 上报 windowId；监听 background 发来的 close 消息时调 `window.close()` 自关
  - popup 查 `getSidePanelState({windowId})` 取实时状态，按钮文案随之切
  - SW 重启 / 扩展重载时 sidepanel 端 `port.onDisconnect` 触发，500ms 后自动重连，避免状态假报
- 新增 `docs/KNOWN_ISSUES.md`：归档 `chrome://contextual-tasks/`（Chrome 内嵌 Google AI Mode 的内部协议页）关键字提取问题
  - 层 A 可修：`keywords.js` hostname 分支只匹配 `google.`，不命中 `contextual-tasks`，文档含 5 行修复草稿代码
  - 层 B 不可修：content script 因 chrome:// 协议禁注入，鼠标选区永远拿不到（Chrome 平台层硬限制）

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 无破坏性改动，旧用户升级直接生效

## 已知限制

- `chrome://contextual-tasks/`（Chrome 内嵌 AI Mode）页面：URL 关键字暂不识别（详见 `docs/KNOWN_ISSUES.md`），鼠标选区无法捕获（Chrome 平台层硬限制）
- AI 检测提醒目前只挂在封面生成器入口；其他 AI 任务（速答 / 百问 / 优化）暂未涉及图片生成，未挂提醒

## 升级提示

老用户从 v1.2.1 升级 → 直接用即可，主要感知是：

1. 打开侧边栏会在 header 下方看到一条新的 ⚠️ banner，悬停 ⚠️ 可看完整说明（含 C2PA 原理 / 平台识别后果 / 截图快捷键）
2. 点击扩展图标弹 popup 时，底部按钮文字会按侧边栏当前状态切换 ——「📑 打开侧边栏」或「📕 关闭侧边栏」
3. 用封面生成器跳到 ChatGPT 时，prompt 末尾会多两行温馨提示文字（明确标注「AI 请忽略本段」，ChatGPT 不会画到图里，仅供用户阅读）
