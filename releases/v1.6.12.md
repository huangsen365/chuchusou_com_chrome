# 触触搜 v1.6.12 发布说明

发布日期：2026-05-16

## 一句话总览

修复 **Windows 下 popup 顶部"触触搜"三个字换行**的体验小坑。**无破坏改动、无 storage 变化、无权限变化、对老用户升级完全静默**。

## 主要更新

### 🐛 修复

#### Windows 下 popup 标题换行（macOS / 侧边栏不复现）

**问题表现**：
- 在 Windows Chrome 上点击扩展图标 → popup 弹出 → 顶部蓝色 header 里的"触触搜"三个字会**换两行显示**（"触" 占一行，"触搜" 占下一行，或类似的拆分）
- macOS 上、侧边栏里都没有这个问题

**根因**：
- popup 总宽 280px，header 左右 padding 各 14px → 内容可用宽度 = **252px**
- 右侧关键字徽章容器 `.menu-keyword-wrap` 固定 180px（flex-shrink: 0）
- 留给左侧 `.header-left`（🔍 emoji + "触触搜" 标题）的空间 = 252 - 180 = **72px**
- macOS：苹方/PingFang 字体 15px/600 weight，"触" 约 16px，3 个汉字 ~48px + emoji 18px + gap 6px = **72px**，刚好塞下不换行
- Windows：默认中文字体微软雅黑/YaHei 同字号同 weight 比苹方宽 2-3px，3 个汉字 ~51-54px → 总和 75-78px，**超出 72px 触发换行**

**修复**：
- `.header-left` 加 `flex-shrink: 0` + `white-space: nowrap` —— 强制左侧整块不被压缩、不换行
- `.menu-title` 加 `white-space: nowrap` —— 双重保险，文字本身永不换行
- `.menu-keyword-wrap` 宽度 180px → **170px** —— 给左侧腾 10px
- `.menu-keyword` 徽章 max-width 140px → **130px** —— 同步收紧 ellipsis 触发点

修复后内容区分布：170 (右) + ~75 (左 Windows 实测) = 245px，**留 7px 余量**，macOS / Windows 都安全。

**副作用**：popup 关键字徽章 ellipsis 触发点早 1 个汉字（130px ≈ 8-9 个汉字）。考虑到 popup 本来就窄、hover 仍有完整 tooltip、且大多数关键字 ≤ 8 字，可以接受。侧边栏徽章不变。
