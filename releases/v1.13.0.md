# 触触搜 v1.13.0 发布说明

发布日期：2026-09-17

## 一句话总览

**新增「墨清风格」封面预设，长文「生成封面」终于跟随你在侧边栏选的风格，速答 ChatGPT 默认开推理模式；触触搜正式以 MIT 协议开源。**

## 主要更新

### ✨ 新功能

#### 新增封面风格「✒️ 墨清风格」

由 [朱墨清 @zzqgz7326](https://x.com/zzqgz7326) 设计的版式：

- 左上角绝大部分区域分三行显示醒目主标题（也可拆开显示）
- 右手边五分之一竖向显示副标题
- 底部五分之一横向显示另一条副标题，所有主副标题互不重复
- 副标题字号不能太小，约为主标题的二分之一
- 整体风格根据文章内容自适配

右键菜单「封面生成器」、Popup、侧边栏置顶风格选择器三处同步出现；「打开以下全部预设风格」也会一起开出它。

#### 长文「生成封面」跟随侧边栏置顶的风格

此前 ChatGPT 长文页的「生成封面」按钮**固定用极简留白**，你在侧边栏把封面生成器切到别的风格它也不管——只有比例是跟着走的，所以会出现「比例对了、风格不对」的迷惑现象。

现在它按侧边栏置顶来：

- 置顶的是内置风格（墨清 / 小红书 / 椰树牌 / 二次元 / 极简）→ 用该风格
- 置顶的是「自定义风格」→ 用你当前应用的那一行；没保存过行则用预设库第一行
- 没置顶、置顶的不是封面任务、自定义没有文本 → 仍用极简留白（老行为）
- 置顶的风格已从配置里删掉或运行时打不开 → 自动退回极简留白重试一次，按钮不会死

点完按钮显示「✓ 已完成 · ✒️ 墨清风格」，toast 也带风格名。按钮悬停提示改为「风格跟随侧边栏置顶的封面风格（未置顶时用极简留白）」。

#### 侧边栏风格选择器显示作者署名

带署名的风格在行尾多一个低调的 ⓘ：悬停显示「由 朱墨清 设计 · https://x.com/zzqgz7326（点击打开）」，点击新标签打开作者主页，不会误切换单选。署名来自 `coverPrompts.json` 的 `credit` 字段，以后任何风格加该字段即自动带 ⓘ。

#### 速答壹拾佰的 ChatGPT 默认进入推理模式

ChatGPT 引擎 URL 加上 `hints=reason`。短 prompt 直连和长 prompt 后台中继两条路径都保留该参数（中继只剥 `q / prompt / query / text`）。X / 知乎帖子旁的闪电按钮走同一引擎表，一并生效。触触搜百问与优化提示词的 ChatGPT 入口保持 `?q=` 不变。

### 🛠 技术改动

- `background/articleActions.js` 新增 `resolvePinnedCoverStyle()` / `coverCategoryExists()` / `coverStyleLabel()`；`createLongArticleCover` 响应新增 `categoryId` 与 `styleLabel`。三个 storage key 字面量与 `src/shared/coverPinConstants.ts` 逐字一致，由 `verify:long-article-actions` 锁定；该脚本的封面断言扩为 7 种场景（无置顶 / 内置风格 / 自定义选中行 / 自定义无行回退首行 / 自定义无文本回退 / 非封面置顶 / 风格失效重试）。
- `coverPrompts.json` 分类新增可选 `credit { name, url }`；legacy `sidepanel/sidepanel.js` 与 TS `src/sidepanel/PinnedAction.ts` 同步渲染，样式 `.sp-pin-option-credit`。冒烟新增一步：先 `Target.activateTarget` 激活侧边栏页（置顶区初始化走 `requestIdleCallback`，后台标签不触发）→ 等 `#spPin` 就绪 → 打开 picker → 断言 ⓘ 的 href / target / rel / title / 其它风格无 → 还原活动标签。
- 墨清风格：`coverPrompts.json` 双轨新增 `zhumoqing` 分类（label「墨清风格」），4 份标题表 + 4 份 `MENU_DEFINITIONS` 登记，图标 ✒️；`verify:cover-consistency` 6 个风格三入口一致。
- `fastAnswersPrompts.json` 双轨 ChatGPT `urlPattern` → `https://chatgpt.com/?hints=reason&q=${PROMPT}`。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖、无新增站点匹配
- 已保存的置顶风格、自定义预设、比例全部沿用；此前置顶了非极简风格的用户，本版起长文「生成封面」会自动改用该风格（见升级提示）
- 未删除任何菜单项或入口

## 已知限制

- 沿用 v1.12.1 已知限制
- 「墨清风格」的版式是提示词层面的约束，实际布局仍由 ChatGPT Images 决定，个别情况下三行标题 / 竖排副标题可能不完全达标；不满意可回到侧边栏「自定义风格」微调字眼
- `hints=reason` 是 ChatGPT 的 URL 提示参数，若 ChatGPT 侧调整该参数语义，行为可能变化；不影响提示词填入
- 署名 ⓘ 只在侧边栏置顶风格选择器里显示，右键菜单 / Popup 的菜单项本身不带

## 升级提示

- **长文「生成封面」行为变化**：如果你之前在侧边栏把封面生成器置顶到了非极简风格（或自定义风格），本版起 ChatGPT 长文页点「生成封面」会用那个风格，而不再是极简留白。想要极简留白就把置顶切回去
- 速答 ChatGPT 会直接进入推理模式，响应时间可能比之前长一些，回答更深入
- 侧边栏风格列表多了「✒️ 墨清风格」，行尾 ⓘ 是作者署名，点它只是打开作者主页
- 其余功能与 v1.12.1 一致
