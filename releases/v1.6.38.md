# 触触搜 v1.6.38 发布说明

发布日期：2026-07-10

## 一句话总览

**文心一言迁移到官方新入口 `chat.baidu.com`** —— 修复老域名退役导致的打不开/丢关键字；同时给选中文字右键菜单标题瘦身。

## 主要更新

### 🐛 修复

#### 文心一言打不开 / 关键字丢失

百度已将旧域名 `yiyan.baidu.com` 退役为"升级通知页"，原有的"选中文字跳文心并带上关键字"链路实际失效。本版全面切换到官方新入口 `https://chat.baidu.com/?enter_type=yiyan_site`。

新入口不再支持用 `?q=` 网址参数携带关键字，因此改为**后台中转（storage relay）+ 内容脚本自动填入输入框**的方式投递选中文字/提示词——短句也走这条路，确保稳定。存量保存的旧文心链接会被自动改写迁移到新入口，不会打到失效页面。

老 `yiyan.baidu.com` 页面专用的 Slate 编辑器注入逻辑保留、且严格锁定只在老域名生效；新站是普通输入框，走通用填值路径，二者互不干扰。

### 🔧 改进

#### 选中文字右键菜单标题瘦身

此前选中文字后右键，主项、各分组标题、以及**每一个可点击子项**（各搜索引擎 / AI 对话 / 速答）都会重复显示一遍选中的关键字，视觉冗余。本版调整为：只在菜单顶层与各级分组标题上显示关键字（仍由 Chrome 原生 `%s` 在绘制瞬间代入，第一次右键即显、零竞速），可点击的具体子项恢复简洁固定标题。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **改动范围**：文心引擎 URL（config/prompts 及镜像）、AI prompt relay（`chatgptPromptRelay.js`）、内容脚本填值（`content.js`）、右键菜单构建（`menuBuilderAttach.ts`）、以及相应校验脚本。不动 storage schema、消息协议主体、其他引擎。

## 已知限制

- 文心新入口 `chat.baidu.com` 的真实填充效果依赖百度页面的输入框结构；自动化冒烟已验证中转管道与新域名契约（新域名 / 无 q / relay id + tab 绑定），但真站输入框的实际填充与是否自动发送需以真实页面为准，升级后如遇个别不填充情况欢迎反馈。
- 沿用前版已知限制。

## 升级提示

- 从 v1.6.37 升级：商店推送后自动更新即可

- 主观感受二：选中文字右键时，各具体子项标题不再重复显示关键字，只在顶层和分组标题上显示

完整商店描述沿用 v1.6.20 大版本（本版为修复 + UI 微调，无新增功能、无新权限）。
