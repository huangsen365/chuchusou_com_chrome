# 触触搜 v1.6.40 发布说明

发布日期：2026-07-10

## 一句话总览

**修复右键菜单「X（推特）搜索」在个别环境下点击静默无反应** —— 补上与百度/谷歌同款的兜底通道。

## 主要更新

### 🐛 修复

#### 右键「X（推特）搜索」可能点了没反应

X 搜索（v1.6.35 新增）此前是全扩展唯一只依赖统一 URL 通道（SSoT/URLBuilder）、没有 legacy switch-case 兜底的搜索项。一旦统一通道在个别环境未就位（如配置加载失败），右键点它就静默无反应；而百度/谷歌等老项都有兜底分支所以一切正常，popup 入口又因消息自带 URL 模板不受影响——形成"popup 能用、右键不能用"的费解症状。

本版在两处入口（右键 onClicked / popup 老消息路径）都补上 `ccs-x` 的兜底分支。真机破坏性验证：人为让统一通道全部失效后触发右键 X 搜索，兜底正确打开 `x.com/search?q=关键字`（修复前该场景零反应）。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **改动范围**：仅 `src/background/menuHandlersAttach.ts` / `background/events.js` 两处 switch-case 各 +1 分支。不动配置、存储、其他菜单项

## 已知限制

- 沿用 v1.6.39 已知限制
- X 站内搜索结果页需要登录 X 账号才能查看（站方限制，与扩展无关）

## 升级提示

- 从 v1.6.39 升级：商店推送后自动更新即可
- 若你此前遇到"右键点 X 搜索没反应、popup 里点却正常"，升级后右键应恢复正常；如仍有异常欢迎反馈（有助于定位统一通道未就位的根因）

完整商店描述沿用 v1.6.20 大版本（本版为单点修复，无新增功能、无新权限）。
