# 触触搜 v1.18.9 发布说明

发布日期：2026-09-29

## 一句话总览

**封面生成器新增「🎀 韩系粉色」风格**（@inwelove 设计），同时把封面风格改成一个风格一个文件，以后新增风格更省事。

## 主要更新

### ✨ 新功能

#### 新封面风格「🎀 韩系粉色」

- **视觉方向**：粉色图案拼贴流行 + K-style 潮流编辑 + 韩国时尚杂志 + 2D 平面海报
- **配色**：奶油粉、柔粉、桃粉、奶油白、银灰为主，少量黑色用于文字和细线
- **元素**：棋盘、波点、照片框、几何色块、心形轮廓、手绘线条、小贴纸，以重叠、错位、裁切制造动感
- **排版**：超大标题是第一视觉中心，1～3 个关键词做标签或贴纸，不对称拼贴构图，保留奶油白留白
- **约束**：保持平面 2D，不做金属、玻璃、厚重立体字等 3D 材质；画面文字只取自用户选中的内容，不添加固定英文标语或品牌名；出现人物时不遮挡脸部
- **作者**：[@inwelove](https://x.com/inwelove/articles)，侧边栏置顶风格选择器里该风格行尾的 ⓘ 可查看并打开作者的文章页

右键菜单、popup、侧边栏三个入口都能直接使用，也会出现在「打开以下全部预设风格」里。画面比例跟随侧边栏的比例选择（原提示词固定的 5:2 已改为跟随用户选择）。

### 🔧 改进

- 侧边栏帮助文字与 README 加入韩系粉色的作者署名。

### 🛠 技术改动

- **封面风格一个风格一个文件**：`prompts/cover/<id>.json` 放名称、emoji、说明、署名和配色，`prompts/cover/index.json` 决定显示顺序；说明很长的风格可以另放同名 `.md` 文件。构建时组装成运行时读取的 `prompts/coverPrompts.json`，扩展的读取代码没有变化；组装结果与拆分前逐项一致（只多了 emoji 字段）。
- **菜单标题不再手抄**：右键菜单与 popup 的风格标题统一由「emoji + 空格 + 名称」生成，删掉 4 张需要手动同步的标题表；原有 5 个风格的标题逐字不变。
- **守卫**：`verify:cover-consistency` 检查风格文件（缺文件、多余文件、未引用的 `.md`、缺 emoji、署名格式）；冒烟测试在真 Chrome 里检查韩系粉色的选择器行与署名链接。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无存储结构变化、无服务器依赖
- 已置顶的封面风格与自定义风格不受影响
