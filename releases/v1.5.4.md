# 触触搜 v1.5.4 发布说明

发布日期：2026-05-02

## 一句话总览

侧边栏顶部蓝色 header 锁高度——切换页面时不再因关键字徽章出现/消失而上下抖动 4px。

## 主要更新

### 🐛 修复

#### 顶部蓝色 header 在页面切换时上下跳跃

**用户反馈**：频繁切换页面时（有些页面有关键字提取、有些没有），侧边栏最顶部那块蓝色 header 会有一种小小的跳跃感。

**根因**（实测）：

| 元素 | 高度 |
|---|---|
| 左侧 logo + 标题 `.sp-header-left` | 15.6px（font 13px × line-height 1.2） |
| 关键字徽章 `.sp-keyword` | 19.4px（font 11px × line-height 1.4 + padding 2px×2） |

`.sp-header` 用 `align-items: center` + padding 6/6，整高跟随最高子元素：

- 无关键字时（badge `display:none`）：6 + **15.6** + 6 ≈ **28px**
- 有关键字时（badge 19.4px）：6 + **19.4** + 6 ≈ **32px**

切换页面时 header 在 28 ↔ 32 之间反复跳，下面 sticky 区跟着位移，是用户感知到的"抖一下"。

**修复**：

`.sp-header` 加 `min-height: 32px` + `box-sizing: border-box`，按"有 keyword"基线兜底——keyword 徽章消失时 header 仍维持 32px，**整个 sticky 区永远稳定**。

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 与 v1.5.3 完全兼容，旧用户升级直接生效
- 无 storage / 接口改动

## 已知限制

- v1.5.3 报告里提到的 `.sp-clipboard-btn` 36px 显隐差（无 keyword 页面 vs 有 keyword 页面切换时下方菜单大幅位移）**本版未修**。需要时再单独决策（已做了三选一方案设计）。

## 升级提示

老用户升级后，频繁在"有关键字 / 无关键字"页面间切换时，**侧边栏顶部 header 不再轻微抖动**，整体观感更稳定。如果你之前感受到那种轻微跳跃，升级后会立刻消失。
