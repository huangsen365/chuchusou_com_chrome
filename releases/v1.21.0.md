# 触触搜 v1.21.0 发布说明

发布日期：2026-10-18

## 一句话总览

**X 和知乎上的速答闪电可以选 ChatGPT、Gemini、Claude。**

## 主要更新

### ✨ 新功能

#### 速答闪电选引擎

X 推文、X 长文、知乎回答 / 文章旁边的速答闪电，以前只能发到 ChatGPT。现在：

- **点闪电**：发到默认引擎。默认仍是 ChatGPT，老用户的习惯不变
- **鼠标停一下**（约 0.35 秒）：弹出「这次发到 ChatGPT / Gemini / Claude」，选哪家只这一次发过去，默认不变
- **设为默认**：浮层每行有「设为默认」，改了之后直接点闪电就发到那家；其它已打开的 X / 知乎页面也跟着变
- **键盘**：焦点在闪电上按 ↓ 打开浮层，Esc 关闭并把焦点还给闪电
- 浮层跟着网站深浅色，放在闪电正上方（上方放不下就放下方），点浮层不会误开 X 帖子
- 只放这三家，是因为「选A并优化改写 → 注入X草稿 / 生成封面」整条链路只在这三家走得通

#### 连发几家对比

- 发完一家后闪电变绿「已发送」但不锁住，还能悬停选另一家；浮层里刚发过的那家显示「已发送」，3 秒内不会重发
- 发送失败后点「重试」，发回失败的那一家

### 🛠 技术改动

- 引擎选择在共享运行时 `modules/siteFastQaRuntime.js` 里（挂在 body 上的 shadow DOM，不受网站样式影响），X / 知乎适配器只改文案；以后新接的网站自动带选引擎。投递走 `ccs-fastqa-<引擎>-quick`，与右键「速答快捷」同一条后台链路
- 默认引擎存 `ccs_site_fastqa_engine`（已登记 `shared/storageKeys.js`）
- 后台新增消息 `ccsGetEngineLabels`：内容脚本读不到扩展里的 `config/engines.json`（没开 web_accessible_resources），引擎名与图标由后台代读
- 冒烟测试（真 Chrome）新增引擎浮层场景：悬停弹出三家、临时选 Gemini 真开 Gemini 且默认不变、已发送那家锁住、设 Claude 为默认后点闪电真开 Claude、Esc 关闭、键盘 ↓ 打开与焦点归还
- 真机复核：在真实 X（深色）与知乎（浅色）页面运行与仓库逐字一致（SHA-256 核对）的新代码，发送被拦截只做记录——浮层位置与深浅色正确、点浮层不误开 X 帖子、知乎选 Claude 先展开「阅读全文」再发出全文、默认不变

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无服务器依赖；新增一个设置项（速答闪电的默认引擎），没设置过时按 ChatGPT
- 右键 / Popup / 侧边栏的速答不受影响

## 已知限制

- 沿用 v1.20.0 已知限制
- 浮层只有 ChatGPT、Gemini、Claude；Grok、文心一言仍可从右键「速答快捷」发
- 默认引擎目前只能在浮层里改，Popup / 侧边栏暂无对应设置项
- 目标 AI 网站没登录时，与右键速答发到该引擎的表现一致

## 升级提示

- 升级后**已打开的 X / 知乎页面需要刷新一次**才有引擎浮层（旧按钮会提示「扩展已升级，点击刷新页面后继续使用速答」）
- 默认引擎仍是 ChatGPT，不设置就和以前一样

## 商店描述（300 字以内，上架直接用）

触触搜速答、触触搜百问、提示词优化可一键发到 ChatGPT、Claude、Gemini、Grok、文心一言、Google AI，提示词自动填进输入框。X 推文、X 长文和知乎回答旁的速答闪电现在可选 ChatGPT、Gemini、Claude：鼠标停一下选这次发哪家，也能设为默认。三家的速答回复都有「选A并优化改写」，改写出的长文可一键「注入X草稿」「生成封面」。另有 Google Docs 一键改写、封面生成器多种风格与配色轮换。所有入口只准备内容并填入输入框，不会自动发送、不会自动发布；全部本地处理，无新增权限和服务器依赖。项目已以 MIT 协议开源。
