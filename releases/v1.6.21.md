# 触触搜 v1.6.21 发布说明

发布日期：2026-05-17

## 一句话总览

**内部 v2 沉淀版本，用户感知与 v1.6.20 完全一致**。`popup-v2/` 与 `sidepanel-v2/` 两套从零重写的完整实现作为储备保留在仓库与 zip 内（未激活），manifest 仍指向旧 popup / 旧 sidepanel —— **生产行为零差异**。

## 主要更新

### 🛠 技术改动

#### 1. popup-v2/ 完整重写（不激活，作储备）

- HTML 189 / CSS 466 / JS 692 = **1347 行**（vs 旧 popup 1077 JS + 复杂 HTML，约 1/3）
- 与旧 popup **功能 1:1**：
  - 关键字 fallback chain（接入 `shared/keywordClient.js` 多层 fallback + 3 段 tab fallback）
  - 23 项菜单（含百问 / 优化二级子菜单，prebuild SSoT 注入）
  - 封面生成器快捷启动卡片 + 跳侧边栏
  - 8 个 settings 按钮（启用 / 黑名单 / 调试 / 语音 / 导出菜单 / 快捷键 / 提示词库 / 欢迎页）
  - 提示词库走 lazy load 旧 `popup/modules/PromptLibraryManager.js`（不复制代码）
  - inline ⚡启用 + 🐞调试 双入口（与 settings panel 标签 storage SSoT 同步）
- 机制特点：0 React / 0 Plasmo bundle / 0 sendMessage 首屏 / 复用 shared 三件套（keywordClient + runtimeClient + logger）

#### 2. sidepanel-v2/ 完整重写（不激活，作储备）

- HTML 119 / CSS 402 / sidepanel.js 843 / voice.js 386 = **1750 行**（vs 旧 sidepanel 3299 行约 53%）
- 与旧 sidepanel **功能 1:1**：
  - 关键字 fallback + 复制 + 🎤 入口 + AI 提示 marquee banner + popover + 剪贴板兜底
  - 完整封面 picker（5 分类 [anime-cute / xiaohongshu / coconut / minimal / custom] + 11 比例预设 + 用户保存 ≤5 个自定义比例 + custom 风格 textarea 行管理 dropdown + 💡 ChatGPT/Google 风格灵感链接 + 📌 Pin + 🚀 直接执行）
  - 19 项 flat 菜单（prebuild SSoT 注入，与旧 sidepanel 共用 renderer）
  - 标签 onActivated / onUpdated 50ms debounce 刷新关键字
  - alive port + 500ms 重连 + close 信号（推迟到 requestIdleCallback，不抢首屏 CPU）
  - Voice 模块 **lazy load**（默认关，`ccs_voice_enabled=true` 用户点🎤 才 dynamic script 加载 voice.js）：13 引擎别名 + Levenshtein + acoustic × match × history boost 融合排序 + intro / recording / candidates / error / permission-help 状态机 + ccsVoicePermissionGranted / ccsVoiceVisibleRecognized / ccsVoiceVisibleError 四个 background push 处理

#### 3. 共享 build 基础设施扩展

- `scripts/prebuild-popup-menu.mjs` 同时注入静态菜单到 4 个路径：
  - `build/popup/popup.html`（旧 popup）
  - `build/popup-v2/popup.html`（v2 储备）
  - `build/sidepanel/sidepanel.html`（旧 sidepanel）
  - `build/sidepanel-v2/sidepanel.html`（v2 储备）
- `scripts/plasmo-compat-postbuild.mjs` copyDirs 数组加 `popup-v2` + `sidepanel-v2`

build/ 里 v2 文件夹一直存在，但 Chrome 不会加载（manifest 不指向它们），所以**零生产影响**。

#### 4. Manifest 入口

```json
"action": { "default_popup": "popup/popup.html" }
"side_panel": { "default_path": "sidepanel/sidepanel.html" }
```

**与 v1.6.20 完全一致**。

## 兼容性

- Chrome 114+（不变）
- Manifest V3
- 用户已有数据全部兼容（storage key 没改一个）

## 已知限制

- v2 实现是从零重写的"功能 1:1 + 机制更精简"版本，**未生产激活**。如未来想切回 v2，只需 manifest 改两行：`default_popup: popup-v2/popup.html` + `default_path: sidepanel-v2/sidepanel.html`，build + 发版即可。
- 沉淀代码不会运行也不会拖性能，但占了一点点 zip 体积（~75KB 增加）。

## 升级提示

从 v1.6.20 升级：商店推送后浏览器自动更新即可。**无任何用户可见行为差异**。

唯一变化是 zip 内多了 `popup-v2/` 和 `sidepanel-v2/` 两个文件夹（dead code）—— 这些代码代表 4 个开发周期（11 个 popup-v2 commit + 5 个 sidepanel-v2 commit）的设计探索成果，作为未来一旦旧 popup / sidepanel 出现新性能问题时的快速切换预案保留。
