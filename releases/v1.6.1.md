# 触触搜 v1.6.1 发布说明

发布日期：2026-05-12

## 一句话总览

封面生成器扩容：新增「二次元可爱」「极简的留白」两个内置风格，自定义风格 textarea 上限从 600 字大幅放宽到 5000 字，引导词同步更新。

## 主要更新

### ✨ 新功能

#### 新增内置封面风格「二次元可爱」

日系二次元可爱风格（随机各种）—— purpose 简洁开放，让 ChatGPT Images 2.0 在粉嫩马卡龙色调 / 圆润柔和线条 / 大眼睛 Q 版角色 / 赛璐璐 / 水彩质感 / 卡哇伊氛围这个宽泛维度里自由发挥，可能点缀星光 / 爱心 / 樱花等少女系元素。

右键菜单 / Popup / Sidepanel 三个入口同步出现，icon 用 🌸。在 sidepanel 「✏️ 编辑」内的封面卡片 radio 列表里直接选即可。

#### 新增内置封面风格「极简的留白」

整体走大面积留白 / 克制装饰 / 黑白灰为主 / 低饱和 / 细线条 / 强调呼吸感与高级感的杂志封面调性。

**关键差异化设计**：会在标题文字里随机挑选 1～2 个关键字眼（或一个核心词组），用一种鲜明饱和的非黑白灰颜色（朱红 / 橙黄 / 钴蓝 / 草绿 / 紫罗兰 / 桃粉 / 柠檬黄 等任选其一）作为重点色加以强调，形成「通篇克制 + 一点鲜活」的视觉焦点。purpose 里明确护栏「不要让重点色蔓延到非关键字之外」，防止 AI 把彩色铺得到处都是。

icon 用 ⬜（白方块象征留白）。适合知识 / 读书 / 产品介绍 / 极简风视频号封面等场景。

### 🔧 改进

#### 自定义风格 textarea 上限 600 → 5000 字

之前 600 字撑不下逐行加详细解释的预设库（比如「二次元可爱」这类风格描述本身就接近 50 字）。本次三处同步放宽：

- HTML `maxlength="5000"`
- 计数器显示「/ 5000」
- JS 保存时兜底截断 `CUSTOM_PURPOSE_MAX = 5000`

注意：textarea 总容量是 5000，但**真正的瓶颈是单行**（被选中那行注入到 `${purpose}` 占位 + 模板 + 选中文本一起 URL-encode 后送给 ChatGPT）。单行建议 ≤ 1500 中文字符比较稳。

#### 「💡 不知道填什么？」引导词全面更新

跳 ChatGPT 让它列 30 个风格名的那个引导词换成《幸运星》系参考标尺：

- **聚焦方向**：日系二次元日常 / 校园 / 轻喜剧 / 吐槽 / 宅文化 / 社团 / 空气系
- **平衡要求**：男女角色风格尽量对半，避免清一色女生日常或萌系少女风
- **避忌清单**：避免黑暗 / 热血战斗 / 赛博朋克 / 恐怖 / 末世 / 写实厚涂 / 欧美漫画风
- **输出格式**：纯文本，奇偶行交替（奇数行完整句式描述图片/文字/角色/配色/氛围/点击感；偶数行用「风格名称（关键词补充）」格式）

此外，初版引导词 800 字 → 365 字精简（URL 编码 6595 → 3069 字节），避免部分用户遇到 ChatGPT 端 URL 过长打不开的情况。

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 与 v1.5.4 完全兼容，旧用户升级直接生效
- 无 storage schema 改动；自定义风格已保存的内容继续可用
- 新增的两个内置风格自动出现在右键菜单 / Popup / Sidepanel，无需额外操作

## 已知限制

- 单行 purpose 建议 ≤ 1500 中文字符（受 ChatGPT `?prompt=` 参数 URL 长度上限影响）。textarea 总容量 5000 是预设库容量，不是单行容量。
- 「极简的留白」的"随机重点色"由 ChatGPT 决定，同一标题多次生成可能给出不同颜色；如需固定，请在自定义风格里写死颜色后保存预设。

## 升级提示

老用户升级后，**侧边栏「✏️ 编辑」打开封面卡片 → 看到 radio 列表多了两个内置选项**（🌸 二次元可爱 / ⬜ 极简的留白），右键菜单与 Popup 也同步出现。

如果你之前用「自定义风格」保存过多行预设但被 600 字上限挡到，本次升级后可以继续往里加。
