# 触触搜 v1.6.0 发布说明

发布日期：2026-05-11

## 一句话总览

本版聚焦侧边栏与 Popup 的日常使用体验：关键字复制更方便、完整关键字悬停即显，并新增默认关闭的实验性语音选引擎能力。

## 主要更新

### ✨ 新功能

#### Popup / 侧边栏关键字一键复制

Popup 和侧边栏顶部的关键字徽章旁新增 📋 复制按钮。用户看到当前关键字后，可以直接复制完整内容到剪贴板，不需要再手动选中短徽章或回到原网页重新复制。

侧边栏复制时优先使用 raw 原文，适合长段落、多行文本和 AI prompt 场景；视觉展示仍保持紧凑，不影响顶部 header。

#### 实验性语音选引擎（默认关闭）

新增语音选引擎入口。开启后，在侧边栏已有关键字时可点击 🎤，说出“百度”“GPT”“知乎”等引擎名，系统会展示候选结果供用户确认。

设计原则：

- 默认关闭，不打扰现有用户
- 只识别引擎名，不上传或朗读用户选中的关键字
- 不自动跳转，始终让用户从候选中确认

### 🐛 修复

#### 完整关键字悬停显示慢

之前 Popup / 侧边栏顶部关键字用浏览器原生 `title` 显示完整内容。原生 tooltip 有浏览器控制的延迟，用户把鼠标放上去后会感觉慢半拍。

本版改为自定义即时 tooltip：

- 鼠标移上去几乎立即显示
- 支持换行和长文本滚动
- 深色浮层更易读
- 不再被短徽章的省略号区域裁切

#### 封面生成器说明弹层自动收起

侧边栏里的封面生成器 ⓘ 说明弹层现在会在侧边栏失焦、页面隐藏、窗口切换等场景下自动收起，避免用户回来后看到一个已经不对应当前注意力状态的浮层。

#### 剪贴板关键字按钮持续可用

侧边栏剪贴板按钮在已有关键字时不再消失，而是变成“从剪贴板更新关键字”。这让用户可以随时用剪贴板内容替换当前关键字，不必先切换页面或清空状态。

### 🔧 改进

#### 封面风格参考继续打磨

继续优化封面生成器相关提示和风格参考入口，帮助用户更快获得可用的封面风格关键词。

#### 关键字浮层视觉优化

完整关键字浮层统一采用深色背景、合理宽度、最大高度和滚动兜底；长文本、多行文本的可读性更好。

### 🛠 技术改动

- 语音识别流程通过 MV3 offscreen workaround 接入，避开 Service Worker 不能直接使用页面能力的限制。
- Popup / Side panel 的完整关键字提示从原生 `title` 迁移到 `data-full-keyword` + CSS hover/focus-within，避免浏览器 tooltip 延迟。
- release 版本号同步到 `manifest.json` / `package.json` / `package-lock.json`。

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 与 v1.5.4 完全兼容，旧用户升级直接生效
- 无破坏性存储 schema 变更
- 语音功能默认关闭，不影响未启用用户

## 已知限制

- 语音选引擎仍是实验性功能，识别质量受浏览器语音识别能力、系统麦克风权限和网络状态影响。
- Chrome 当前仍不支持为 `chrome.contextMenus` 原生右键菜单指定图标，菜单图标配置保留但浏览器会忽略。

## 升级提示

老用户升级后不会自动弹欢迎页。日常使用中最直接的变化是：Popup / 侧边栏顶部关键字可以一键复制，鼠标悬停查看完整关键字也会更快。语音选引擎默认关闭，需要在设置中主动开启后才会出现。

## 商店描述（300 字以内，上架直接用）

触触搜 v1.6.0 优化了 Popup 与侧边栏的关键字体验：顶部关键字新增一键复制，完整关键字悬停即显，不再等待浏览器原生提示延迟；侧边栏剪贴板按钮可随时更新关键字，封面生成器说明弹层会在失焦时自动收起。本版还加入默认关闭的实验性语音选引擎功能，开启后可通过语音说出引擎名并从候选中确认。
