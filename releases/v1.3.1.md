# 触触搜 v1.3.1 发布说明

发布日期：2026-04-30

## 一句话总览

Chrome Web Store 列表标题和简介强化关键词，提升商店搜索命中率（功能本身无变化）。

## 主要更新

### 🔧 改进

- **商店列表标题**：「触触搜」→「触触搜 - 多 AI 速答、封面生成器、提示词优化」（25 字符，远低于商店 45 字符上限）
- **商店列表简介**：「选中文本快速搜索和处理工具」→「选中文本快速搜索和处理工具，含封面生成器（内置小红书 / 椰树牌风格）」（35 字符，远低于商店 132 字符上限），避开「新功能 / 目前两款」等会过期的措辞

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 无破坏性改动，旧用户升级直接生效
- **功能本身没有变化**，仅商店列表展示优化

## 升级提示

老用户从 v1.3.0 升级 → 用户体验完全无差异，唯一变化是 `chrome://extensions/` 列表里看到扩展名变长。
