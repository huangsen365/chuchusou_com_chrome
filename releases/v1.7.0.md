# 触触搜 v1.7.0 发布说明

发布日期：2026-08-16

## 一句话总览

**X 推文正文一键速答 ChatGPT** —— 每条有正文的推文旁直接出现闪电入口，无需手动选中，只把主推文正文交给速答，内容更干净。

## 主要更新

### ✨ 新功能

#### 每条推文旁直接速答

在 X（Twitter）的时间线、搜索结果和单条推文页面中，每条有文字正文的推文操作栏都会出现一个闪电按钮。点击后，触触搜直接调用现有「速答 · ChatGPT」流程，打开 ChatGPT 并填入准备好的速答提示词。

X 是动态页面：滚动时间线、切换路由或加载新推文时，按钮会自动补到新出现的推文上。发送过程中显示加载状态，成功或失败会改变按钮状态并弹出提示，避免重复点击和无反馈。

#### 只发送主推文正文

送入速答模板的原始材料严格限定为：

```text
【推文正文】
……
【正文结束】
```

不会附带作者、账号、发布时间、永久链接、外部链接或媒体数量；引用推文、嵌套推文和链接卡片正文也会被排除。这样可以减少元数据和上下文噪声，让 ChatGPT 聚焦于用户真正点击的推文内容。

只有图片、视频或引用内容、但没有主推文文字的帖子不会显示可执行入口，也不会误把引用推文当成正文发送。

### 🛠 技术改动

- 页面侧新增 X 专用正文提取和操作栏注入模块，支持 `x.com` 与 `twitter.com`，仅在顶层页面运行。
- 发送端复用现有 `fastqa → ChatGPT → Prompt Relay → 编辑器填入` 链路；多行内容和较长提示词继续走已有存储中继，不复制第二套 ChatGPT 填入逻辑。
- legacy 生产脚本与 TypeScript/Plasmo 源码双轨同步，保证当前商店构建和后续迁移入口行为一致。
- 新增自动化回归校验，覆盖主推文提取、引用卡片排除、嵌套 article 排除、空正文拒绝及最终正文块格式。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- 无新增权限、无存储结构变化、无服务器依赖
- 原有右键菜单、Popup、侧边栏和「速答 · ChatGPT」入口行为不变

## 已知限制

- 入口依赖 X 当前页面结构；如果 X 日后调整推文 DOM 标记，可能需要同步更新选择器
- 本功能有意只读取主推文文字；图片、视频、作者信息、链接元数据和引用推文不会发送
- ChatGPT 的打开与自动填入仍需要可访问 `chatgpt.com`，并受用户当前登录状态影响

## 升级提示

- 从 v1.6.43 升级：重新打开或刷新 X 页面后，有文字正文的推文操作栏会出现闪电按钮；点击即可执行「速答 · ChatGPT」
- 不需要迁移设置，也不会改变已有菜单布局和速答模板

## 商店描述（300 字以内，上架直接用）

触触搜新增 X 推文一键速答：在时间线、搜索结果或单条推文页面中，点击推文操作栏的闪电按钮，即可把当前推文交给 ChatGPT 生成短篇、中篇和按需长篇回答。无需手动选中文字，只发送主推文正文，不附带作者、时间、链接等元数据，也不会混入引用推文，回答更聚焦。继续支持多 AI 速答、触触搜百问、提示词优化与 ChatGPT Images 2.0 封面生成；全部本地处理，无新增权限和服务器依赖。
