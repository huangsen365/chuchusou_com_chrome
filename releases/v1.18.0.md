# 触触搜 v1.18.0 发布说明

发布日期：2026-09-23

## 一句话总览

**墨清风格封面按 27 组配色轮换** —— 每张封面颜色都不一样，冷暖均衡，相邻两张不撞色。

## 主要更新

### ✨ 新功能

#### 墨清风格配色轮换

此前墨清风格只写了「点缀色例如暖黄或橙」，连续生成的封面颜色大同小异。现在内置 27 组配色方案，每次生成按顺序取下一组：

- 每组是「浅色背景 + 深色主标题 + 一种点缀色」，符合墨清「明亮、不昏暗、只用一种点缀色」的要求
- **点缀色按色轮均衡分配**：红、橙、黄、黄绿、绿、青、天蓝、蓝、靛、紫、品红、玫红 12 个色相各 2 组，另加金、青铜、石墨 3 组中性色，冷暖基本对半
- **背景**取与点缀色相对（补色）或相隔 120° 的淡色，点缀色能跳出来；**主标题**取背景同色相的深色，比统一纯黑更协调
- **相邻两张点缀色在色轮上相隔约 150°**，不会连着两张都是橙；27 张一轮
- 交给 ChatGPT 的是具体指令，例如：「本篇配色：背景以浅色 #E9F4F9（晴空）为基调，主标题用深色 #172C36，点缀色用 #E03A3A（朱红），只点亮一两个关键字；背景插画与整体氛围也沿用这组配色。」
- 只有墨清风格轮换；小红书、椰树牌等靠固定配色辨识的风格不变，用它们也不会推进墨清的轮换进度
- 长文页「生成封面」、右键菜单、Popup、侧边栏所有入口都生效

### 🛠 技术改动

- `prompts/coverPrompts.json` 与 `src/assets-json/` 双轨：墨清 `palettes` 27 组，`purpose` 中「例如暖黄或橙」改为 `${coverPalette}` 占位。
- `background/tasks/AITaskHandler.js` + `src/background/tasks/AITaskHandler.ts`：`collectTaskVars` 对带 `palettes` 且被选中（或「打开全部风格」）的风格读取 `ccs_cover_palette_counter`、取 `palettes[n % 27]`、写回 `n + 1`，渲染为配色指令；异常时回退「点缀色例如暖黄或橙」。TS 侧新增可注入的 `setStorageItem`。
- `AITaskRegistry`（legacy + TS）类别归一化透传 `palettes`，TS 新增 `CategoryPalette` 类型。
- 测试：`verify:cover-consistency` 校验 27 组、十六进制色合法、点缀色不重复、`${coverPalette}` 仅墨清一处；`verify:extension-smoke` 校验长文封面提示词含具体配色、无占位符泄漏、计数器前进。

## 兼容性

- Chrome 114+（不变）；Manifest V3；用户数据全部兼容
- **无新增权限**、无服务器依赖、无新增文件
- 新增一个本地存储键 `ccs_cover_palette_counter`（一个整数，0～26 循环）

## 已知限制

- 沿用 v1.17.9 已知限制
- 配色是提示词层面的指令，ChatGPT 生成的实际颜色可能与色值有偏差，但整体色调会跟着走
- 计数器是本地的，换设备或清除扩展数据后从第 1 组重新开始

## 升级提示

- 从 v1.17.9 升级：墨清风格封面每次颜色不同，属预期；其他风格不变
- 其余功能与 v1.17.9 一致
