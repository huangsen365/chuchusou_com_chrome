# 触触搜 v1.6.2 发布说明

发布日期：2026-05-12

## 一句话总览

商店与文档 SEO 文案更新：manifest 名称 / 描述、README、welcome、package.json 同步加入「ChatGPT Image 2.0」关键字，便于用户在 Chrome Web Store / Google 搜索时命中。无任何代码逻辑变更。

## 主要更新

### 🔧 改进

#### manifest `name` 加入「ChatGPT Image 2.0 封面生成器」

老 name：`触触搜 - 多 AI 速答、封面生成器、提示词优化`

新 name：`触触搜 - ChatGPT Image 2.0 封面生成器 / 多 AI 速答 / 提示词优化`

商店搜索结果与扩展列表中能直接看到核心卖点，便于目标用户识别。约 43 字符，远低于 Chrome 75 字符上限。

#### manifest `description` 加入「基于 ChatGPT Image 2.0」

老 description：`选中文本快速搜索和处理工具，含封面生成器（内置小红书 / 椰树牌 / 二次元可爱 / 极简留白风格）`

新 description：`基于 ChatGPT Image 2.0（ChatGPT Images）的封面生成器（小红书 / 椰树牌 / 二次元可爱 / 极简留白）+ 多 AI 速答 + 文本快速搜索处理`

**关键 SEO 设计**：同时保留「ChatGPT Image 2.0」（用户搜索的常见写法）和「ChatGPT Images」（OpenAI 官方写法），两种搜索拼写都能命中。约 82 字符，在 132 字符上限内。

#### README.md / welcome 页 SEO 文案同步

- **README H1** 由 `# 触触搜 Chrome 插件` 改为 `# 触触搜 Chrome 插件 —— ChatGPT Image 2.0 封面生成器 / 多 AI 速答 / 提示词优化`
- **README 引导块**：tagline 下方新增一段以 🎨 开头的封面生成器 SEO 引导语
- **welcome/welcome.html tagline**：由 `选中文本即用 AI 的 Chrome 扩展` 改为 `选中文本即用 AI 的 Chrome 扩展 —— 基于 ChatGPT Image 2.0 的封面生成器 / 多 AI 速答 / 提示词优化`

#### package.json `description` 替换为功能描述

老 description：`**触触搜** —— 轻触即搜，一触即达。`

新 description：`**触触搜** —— 基于 ChatGPT Image 2.0 的封面生成器（小红书 / 椰树牌 / 二次元可爱 / 极简留白）+ 多 AI 速答 / 提示词优化 / 选中文本快速搜索处理。`

便于 GitHub Topics / NPM Registry / 第三方扫描器索引到关键功能。
