# 触触搜 v1.2.0 发布说明

发布日期：2026-04-29

## 一句话总览

新增"封面生成器"AI 任务（小红书 / 椰树牌风格 → ChatGPT Images 2.0），侧边栏新增"置顶快捷动作"区块；速答模板改为两步流程（短/中篇先出，长篇按需）。

## 主要更新

### ✨ 新功能

- **封面生成器**：右键菜单 / Popup / 侧边栏三端同步出现"🎨 封面生成器"
  - 小红书封面风格（颜色格调：黄绿蓝红 随机搭配）
  - 椰树牌风格
  - 单击直接跳转 ChatGPT Images 2.0 渲染封面
  - 提示词集中在 `prompts/coverPrompts.json`，未来可平滑扩展更多风格
- **侧边栏置顶动作**：侧边栏顶部固定一个"快捷动作"卡片
  - 默认：封面生成器 · 小红书封面
  - "✏️ 修改"按钮可切换风格，保存到 chrome.storage.local（持久化跨会话）

### 🔧 改进

- **速答模板两步流程**：
  - 第一步只输出"短篇 + 中篇"
  - 末尾追加 A/B 两个选项：A = 续写长篇正文（不带"长篇回答"字样、无追问），B = 把短/中篇润色为更自然的真实表达
  - 短篇限制 80 字以内，便于直接做标题
- **Popup 入口文案**：底部按钮 "📌 面板" → "📑 打开侧边栏"，图标和文案都更直白

### 🛠 技术改动

- 新引擎 `chatgpt-images`（ChatGPT Images 2.0）登记到 `config/engines.json`
- AITaskRegistry 加 `cover` 任务，`KNOWN_ENGINE_IDS` 同步加 `chatgpt-images`
- Constants / unifiedMenuConfig / config / menuBuilder / base / events 共 7 处声明式接入

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 无破坏性改动，旧用户升级直接生效

## 已知限制

- 封面生成器目前仅 1 个引擎（ChatGPT Images 2.0），未来视用户反馈追加 Grok Aurora / 即梦 等
- 侧边栏置顶区只展示封面生成器风格，暂不支持置顶速答/百问等其它任务

## 商店描述（300 字以内，上架直接用）

触触搜——选中文本即用 AI 的 Chrome 浏览器扩展。

🔍 选中任意网页文本，立即获得四种入口：右键菜单、悬浮面板、扩展弹窗、侧边栏。

⚡ 速答壹拾佰：一键多 AI 对比（ChatGPT、Claude、Grok、文心一言、Google AI Mode），三种长度回答按需展开。

💯 触触搜百问：同主题一次问遍五大 AI，避免单一模型偏见。

🧠 优化提示词：八种场景模板（深度研究 / 代码编写 / 内容创作等）一键升级你的提问。

🎨 封面生成器（v1.2.0 新增）：小红书风格、椰树牌风格 × ChatGPT Images 2.0，选中标题一键生成封面图。

📑 侧边栏置顶：把最常用的动作钉在侧边栏，下次打开秒触发。

完全本地处理选中文本，不上传服务器。Manifest V3、Service Worker 架构，资源占用极低。
