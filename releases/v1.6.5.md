# 触触搜 v1.6.5 发布说明

发布日期：2026-05-13

## 一句话总览

UI 一致性微调 + 封面生成器默认风格调整：Popup 复制按钮对齐 sidepanel 的 inline `✓` 反馈、关键字 tooltip 改用天蓝主题色、封面「二次元可爱」调到风格列表第一位并设为新装用户默认置顶。**无破坏改动，无 storage schema 变化，无新依赖。**

## 主要更新

### 🔧 改进

#### Popup 复制按钮反馈对齐 sidepanel

老行为：点击 popup 关键字复制按钮（📋）后弹底部 toast「已复制关键字」，按钮本身无视觉变化。

新行为：点击后按钮原地变绿底 + 文字变 `✓` + disable 1.2s → 自动复原，与 sidepanel 完全一致。错误路径（"没有可复制的关键字" / "复制失败"）仍走 toast。

**为什么改**：两个面板的按钮长得几乎一样（半透明白底圆胶囊，sidepanel 20px / popup 22px），但反馈方式之前不同——sidepanel 是 inline ✓，popup 是 toast。在两个面板间切换时会有微小割裂感。统一为 inline ✓ 后，行为视觉完全对齐，而且 popup 浮层空间紧，inline 反馈也比 toast 更不挡视线。

#### 关键字 hover tooltip 改用天蓝主题色

老背景：`rgba(17, 24, 39, 0.97)`（Tailwind gray-900，几乎纯黑）

新背景：`rgba(3, 105, 161, 0.97)`（sky-700 `#0369a1`，与 header 渐变末端 `#0284c7` 同系深蓝）

**为什么改**：扩展整体是天蓝主题（header 渐变 `#0ea5e9 → #0284c7`、按钮 `#0ea5e9`），但 hover 关键字徽章弹出的预览框是 gray-900 纯黑，色相孤立、突兀。改为 sky-700 后与主题协调度大幅提升。popup 与 sidepanel 两端同步调整。

#### 封面生成器「二次元可爱」调到风格列表第一位

老顺序：小红书 / 椰树牌 / 二次元可爱 / 极简留白

新顺序：**二次元可爱** / 小红书 / 椰树牌 / 极简留白

驱动来源是 `prompts/coverPrompts.json` 的 `categories` 数组顺序——三入口（右键 / popup / sidepanel）菜单渲染都从这里读，改一个文件三端同步。同步对齐的位置：

- `background/utils/Constants.js` 的 `MENU_DEFINITIONS` / `COVER_CATEGORY_TITLES`（lookup map，对齐为可读性）
- `manifest.json` / `package.json` 的 description 文案
- `README.md` / `welcome/welcome.html` / `sidepanel/sidepanel.html` 用户可见文案
- `releases/store-listing.txt` 商店上架模板

**为什么改**：市场判断「二次元可爱」最具传播性，前置主推可提升新装用户首次体验的点击意愿。

#### 新装用户默认置顶切换到「二次元可爱」

`sidepanel/sidepanel.js` 的 `DEFAULT_PIN.categoryId` 从 `xiaohongshu` 改为 `anime-cute`。

**老用户不受影响**：`DEFAULT_PIN` 只是 `chrome.storage.local.ccs_sidepanel_pinned_action` 缺省时的兜底值。任何已经打开过 sidepanel 的老用户都已经把 pin 存进 storage 了，本次改动**不会覆盖**——只对从未打开过 sidepanel 的新装用户生效。

## 兼容性

- Chrome 114+（Manifest V3 + chrome.sidePanel API）
- 与 v1.6.4 完全兼容；无 storage schema 改动、无新依赖
- 老用户升级后看到的差异：
  - Popup 复制按钮的反馈变成 inline ✓（不再有 toast）
  - 关键字 hover 预览框颜色由黑变深蓝
  - 封面生成器风格列表里二次元可爱排第一
  - **不会重置已设置过的置顶**

## 已知限制

无。本次为纯 UX 微调 + 默认值调整。

## 升级提示

- 老用户无需任何操作
- 历史档案 `releases/v1.x.x.md` 与 `CHANGELOG.md` 旧版块保留原状，未追改风格顺序——它们反映各版本发布当时的设计意图
- 商店上架审核通过后，新装用户首次打开 sidepanel 将看到「🌸 二次元可爱」作为默认置顶
