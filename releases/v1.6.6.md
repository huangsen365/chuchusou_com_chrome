# 触触搜 v1.6.6 发布说明

发布日期：2026-05-13

## 一句话总览

封面生成器与三端 UI 一系列微调：新增 X (Twitter / 推特) Banner 比例预设、置顶卡片右上角显示当前比例、复制按钮加大到 26px、关键字 tooltip 加 400ms hover 延迟避免误触；顺手修了一个隐性 CSS class 冲突 bug。**无破坏改动、无 storage schema 变化、无新依赖。**

## 主要更新

### ✨ 新功能

#### 封面生成器新增 6:2 比例预设

排在 5:2 之后作为第二项：
```
5:2 横幅封面（默认）
6:2 X (Twitter / 推特) 个人主页 Banner（1500×500）  ← 新增
2.35:1 微信公众号头图
2:1 横幅卡片（Twitter / 知乎）
...
```

**为什么是 6:2 而不是 3:1**：X 官方 Banner 标准是 1500×500 像素，约掉公因子是 3:1，但用 6:2 与同组其他比例（5:2 / 4:3 等）的表达式形态一致，统一更好。Label 内同时列「X / Twitter / 推特」三种叫法，避免某种叫法的用户搜不到。

SSoT 在 `sidepanel/sidepanel.js` `RATIO_PRESETS`，README / store-listing / sidepanel.html 同步把"10 种预设"改为"11 种"。`DEFAULT_RATIO` 仍为 `5:2`，**不动默认值**——只新装用户从未设置过比例的兜底逻辑用到这个常量，老用户已存的偏好不受影响。

#### 侧边栏置顶卡片显示当前画面比例

卡片右上角内侧低调显示当前选中的比例：

```
┌──────────────────────────────────────────────┐
│                                     5:2      │ ← 10px 琥珀色 0.6 opacity
│ [🎨]  封面生成器  🌸 二次元可爱  ⓘ      [✏️] │
└──────────────────────────────────────────────┘
```

让用户**不点 ✏️ 也能一眼看到当前比例**——之前必须打开 picker 才能确认是 5:2 还是 6:2 / 9:16 等。`absolute` 定位到卡片右上角内侧，`pointer-events: none` 纯展示不拦截任何点击/hover。

`savePicker()` 已有的 `render()` 调用会自动同步比例变更，无需额外接线。

### 🔧 改进

#### 侧边栏置顶卡片重构为单行

原 2 行（任务名 + 风格名）合并为单行：

```
原（2 行）：
┌──────────────────────────────────────────────┐
│ [🎨]  封面生成器（建议字数适中）ⓘ       [✏️] │
│       🌸 二次元可爱                         │
└──────────────────────────────────────────────┘

新（1 行）：
┌──────────────────────────────────────────────┐
│                                     5:2      │
│ [🎨]  封面生成器  🌸 二次元可爱  ⓘ      [✏️] │
└──────────────────────────────────────────────┘
```

- 删掉「（建议字数适中）」冗余文案——ⓘ popover 里本来就有「字数 / 风格 / 比例」完整说明
- 卡片高度净减约半行（4-6px），sticky 区更紧凑
- CSS 顺手清理 `.sp-pin-task-row` / `.sp-pin-style-row` 不再需要的中间容器（净减 16 行）

#### Popup / Sidepanel 复制按钮加大到 26×26

| 位置 | 老 | 新 |
|---|---|---|
| Popup `.menu-keyword-copy` | 22×22 / 12px icon | **26×26 / 14px** |
| Sidepanel `.sp-keyword-copy` | 20×20 / 11px icon | **26×26 / 14px** |
| Sidepanel `.sp-keyword-voice`（语音）| 20×20 / 11px icon | **26×26 / 14px** |

**为什么 26px**：桌面端 icon 按钮舒适触发尺寸 28-32px，20-22 接近 macOS / Material 最小可点击限度。26 是兼顾"显著加大"和"不撑破 sidepanel header `min-height: 32px`"的折中（32-26=6，每边 3px 净空）。Sidepanel 语音按钮与复制按钮相邻，顺带加大避免大小不齐。

#### 关键字 tooltip hover 加 400ms 延迟

之前 hover 立即弹出，鼠标在 header 区域偶然经过（要去点别的）就会被 tooltip 干扰。改造为：

| 触发方式 | 行为 |
|---|---|
| 鼠标 hover | **等 400ms** → 0.15s 淡入显示 |
| Tab 键盘聚焦 | **立即** 0.1s 淡入（主动行为不等）|
| 鼠标移出 / 失去焦点 | 0.15s 淡出（即时反馈）|

400ms 是经过验证的 hover-intent 阈值——比 macOS Finder（300ms）、VSCode（500ms）居中，对停留 1s+ 阅读的用户无感，对偶然经过显著过滤。

技术实现：`::after` 改为常驻 DOM（默认 `opacity:0; visibility:hidden`），不再只在 hover 时通过 `content: attr(...)` 生成——这样 CSS `transition-delay` 才能生效。

### 🐛 修复

#### 隐性 CSS class 冲突 bug

原 `.sp-pin-ratio` 这个 class 同时被两处使用：

- 侧边栏**置顶卡片**的比例小字显示（`<span>`，本期新增）
- 侧边栏**比例 picker** 的容器（`<div>`，白底 + 边框 + padding + `flex-direction: column`）

CSS 同名规则后写的赢，picker 规则把置顶卡片的 `<span>` 渲染成了一个带白底边框、`padding: 10px 12px`、`margin-bottom: 12px` 的大方块——比 14px 文字大了 20-30px，导致这一周肉眼可见的"对不齐"问题。

修复：把置顶卡片的 class 改名为 `.sp-pin-corner-ratio`，彻底解耦。

**经验**：把新元素的 class 名取得与既有元素**首字母前缀相同（sp-pin-***）的时候，要逐字符比对是否已经有 exact 同名规则——尤其在 CSS 文件 800+ 行的情况下，重名 class 翻车不会编译报错，只会运行时被覆盖。
